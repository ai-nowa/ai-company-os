## 観点3: 週1本出荷にどう効くか

**現状の出荷確率式:**

```
出荷確率 = 記事完成率 × いくとの可用性
```

いくとが週末不在・体調不良・別タスク集中でも出荷がブロックされる。

**切り分け表で🟢確定後の式:**

```
出荷確率 = 記事完成率
```

いくとの可用性が出荷確率から外れる。

**具体的な変化:**

| 状況 | 現状 | 🟢確定後 |
|------|------|---------|
| いくとが週末2日不在 | 出荷ブロック（最大48時間） | 影響なし |
| いくとが別件で24時間応答なし | 出荷ブロック | 影響なし |
| AI社員が記事完成 | いくとOK待ちで止まる可能性 | 即出荷可能 |

週1本出荷の継続可能性が「いくととAI社員の共同稼働率」から「AI社員だけの稼働率」になる。
