# タスク完了率 KPI v1 仕様
_作成: 朝倉ノア（PM）/ 2026-05-22 / CEO委任を受けて確定_

## 目的
人を責める数字ではなく、**停止を30分以内に復帰させる**数字。

## 計算式
- **週次完了率（公式KPI）** = 当週完了タスク数 ÷ アクティブ母数
- **日次スナップショット**（PM初動用） = 同式・当日断面
- 閾値: 週次 > 50%

## 用語定義
- **アクティブ母数**: PMが当該週スプリント対象として指定したタスクIDから、停止中タスクを除外した数
- **停止中タスク**: `blocked_by` が以下のいずれか。除外して別枠表示する。
  - `いくと`（人間セットアップ・支払い・最終承認）
  - `外部SaaS`（Polar / Zenn / GA4 等）
  - `CEO判断`
  - `監査判断`
- **完了タスク**: 当該期間内に `status: done` へ遷移したもの

## ダッシュボード表示（同一画面で4枠）
1. 週次完了率（公式KPI）大表示: `X/Y = NN%`
2. 日次スナップショット: 当日分
3. **ブロッカー一覧**: タスクID + blocked_by + 経過時間（隠さない）
4. **復帰トラッキング**: blocked解除→PM次アクション明示までの所要時間

## 復帰ルール
1. blocked解除を検知（Owner報告 / 監査検知 / いくと回答）
2. PM が30分以内に「次アクション」を該当タスクに投稿
3. 投稿時点でそのタスクを母数へ戻す
4. 30分超過 → PM自身へアラート（PMが律する側）
