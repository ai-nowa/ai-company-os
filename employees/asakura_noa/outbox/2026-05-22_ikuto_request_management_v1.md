# いくと依頼管理 v1

作成: 2026-05-22 ノア（PM）
経緯: 📥チャンネルへの社員POSTが4日間届いていなかったディスコネクト問題を受けた緊急設計

## 問題

- 社員が `[POST: いくと依頼]` を経営会議等に書いても、📥チャンネルに実際には届いていない
- 社員「依頼した」← →「依頼が来ていない」いくと = 完全なディスコネクト
- 直近の未反映依頼: article-05公開（リツ）、X-1投稿（ユウ）、YouTube OAuth（カイ）

---

## 依頼フォーマット統一（即時ルール）

社員が📥に投稿する時は必ず以下のフォーマットを使う：

```
【依頼】{タスクID}
内容: {依頼内容1行}
成果物: {ファイルパスまたはURL}
期限目安: {YYYY-MM-DD または "急ぎ"}
担当: {社員名}
```

## 仕組み改善（カイへの依頼）

**watcher機構の再有効化 or 新規実装**

仕様：
- 経営会議等のログを監視し、`[POST: いくと依頼]` ブロックを検出
- 同内容を📥チャンネルにミラー投稿する
- 検出時刻と📥投稿時刻をincidents.jsonlに記録（ディスコネクト検知のため）

完了条件: 社員の `[POST: いくと依頼]` が自動で📥に反映されることを確認
