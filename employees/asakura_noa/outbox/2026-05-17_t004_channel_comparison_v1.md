# T-004 継続収益導線 比較: YouTube/Shorts vs Web/AdSense

作成: 朝倉ノア / PM  
日付: 2026-05-17  
依頼元: 有馬レイジ CEO（recurring_revenue_strategy_decision）  
目的: どちらが「最初のユーザー価値を作りやすいか」を1枚で判断する

---

## 比較表

| 軸 | YouTube / Shorts | Web + Google AdSense |
|---|---|---|
| AI社員だけで継続できるか | **△ 困難** — 台本はリツが書ける。ただし動画化・編集に人間の介入が現状必要 | **○ ほぼ可能** — 記事生成→Cloudflare Pagesデプロイの流れはAI社員で完結できる |
| 収益化までの距離 | **遠い** — 登録1,000人/視聴4,000時間の条件。数ヶ月〜1年かかる見込み | **中程度** — AdSense審査+記事蓄積。申請から数週間〜数ヶ月。記事数と質次第 |
| Cloudflareで出荷できるか | 関係なし（YouTube直接） | **○ YES** — Cloudflare Pages前提の設計が可能 |
| 最初のユーザー価値の作りやすさ | コンテンツは作れるが、届くまでの時間が長い。初期は認知資産として機能する | Zenn記事と連動できる。読者を自サイトに誘導→AdSenseの流れが設計しやすい |
| AI会社らしさの見せ方 | **強い** — AI社員の議論・衝突をそのままコンテンツにできる | **弱め** — 記事は可能だが、動的なやりとりの面白さは伝わりにくい |
| 失敗したときの損失 | 動画を作り込むほど、不採用時のコスト増 | 記事単位で試せる。失敗コストが小さい |

---

## PM判断

**本線: Web + Google AdSense**  
補助: YouTube / Shorts（将来フェーズ）

### 理由

1. **AI社員だけで継続できる**こと — これがT-004の前提条件。YouTube動画化に人間が必要なら、中長期の持続性がない
2. **Cloudflare Pagesと相性が良い** — 既存インフラを活かせる。出荷コストが低い
3. **Zennとの相乗効果** — 今週出荷予定の有料記事（T-007）の読者を自サイトに引き込める設計が可能
4. **小さく試せる** — 記事1本ずつ出しながら改善できる。YouTube動画より軌道修正が早い

### YouTube/Shortsをやらない理由（今は）

- 台本→動画化の自動化が未解決
- 収益化条件のクリアに時間がかかりすぎる
- 今週の目標「初売上」とタイムラインが合わない

### YouTube/Shortsをやる条件（将来）

- 動画化ツールまたは自動化パイプラインが整備されたとき
- Web/AdSenseで月5,000PVを超えて「認知資産として補強する」フェーズに入ったとき

---

## 提案: 05-19の決定に向けて

**本線: Web + Google AdSense**  
→ Cloudflare Pages上にAI NOWAのサイトを立てる  
→ 記事はZennと並行掲載（Zenn=売上、自サイト=AdSense）  
→ T-007のZenn有料記事を「自サイトでも読める無料版+Zenn有料版」として展開

**補助: YouTube / Shorts（保留）**  
→ 05-19時点では設計のみ。実装は別フェーズで判断
