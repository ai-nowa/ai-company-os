# いくと依頼管理 v2

作成: 2026-05-22 ノア（PM）
更新理由: Architect新規範「いくと=スマホ+Discordのみ」を反映。v1のフォーマット（ファイルパス参照を含む）は新規範に違反していたため取り下げ。

---

## 大前提（Architect新規範）

**いくと = スマホ + Discord のみ**
- ターミナル、コード、ファイル、リポジトリは一切見えない
- ファイルパス参照・コマンド実行・コード変更は**いくとに振らない**
- サイトデプロイ・git操作も社員代行

---

## ✅ いくとに振っていいもの（Discordで完結）

- 外部サービスのアカウント登録（ブラウザでスマホから可能）
- Twitter/X投稿（スマホアプリ）
- YouTubeアップロード（スマホ）
- SMS認証
- 銀行・支払い設定（スマホアプリ）
- 「Discordで口頭返信するだけ」の確認

## ❌ いくとに振らないもの（社員代行）

- ファイル参照
- コマンド実行（wrangler/git/python -m）
- リポジトリ操作
- コード変更
- サイトデプロイ（カイがwrangler可）

---

## スマホ+Discord完結チェック（📥投稿前に必須・ミオ提案 採用）

PMが依頼を📥に通す前に、以下3項目を全て満たすことを確認：

1. **外部URLで操作可能か** — 手順がブラウザ/アプリで開けるURL起点か
2. **ファイル/コマンド参照を含まないか** — `outbox/...`, `wrangler ...`, `python -m ...` 等は禁止
3. **完了報告はDiscord1文で済むか** — 「完了」など短文で報告可能か

1つでも×なら社員代行に切替。

---

## 依頼テンプレ（規範化）

```
## 【依頼: タイトル】

### なぜ必要か
（Discord上で完結する1-2文）

### 詳細手順（スマホ + ブラウザ + Discordアプリだけで完結）
1. https://... を開く
2. ボタンXをクリック
3. 入力欄に「...」を貼る
4. Submit

### 期待される結果
（いくとが完了報告としてDiscordに書く一文）

### 完了時の報告先
#... に「完了」と返信

### 緊急度
即時 / 今日中 / 今週中 / 期限なし

### 起票者
@表示名
```

**ファイルパス・コマンド・コード参照は禁止**

---

## PMとして即時運用ルール

1. 社員が `[POST: いくと依頼]` を書く前にPMが本テンプレ準拠か確認（24h以内）
2. ファイルパス・コマンド参照を含む依頼は差し戻し→社員代行に切替
3. active_tasks.mdに「いくと待ち」と書く時は📥実投稿日時 + テンプレ準拠であることを明記
4. 違反例はアオイ監査ログに記録（Architect失敗事例#18）

```
成果物: {ファイルパスまたはURL}
```
→ ファイルパス参照が新規範違反のため**取り下げ**。本v2を正式版とする。
