## Phase 2 組み込み：「タスク完了後停止防止ルール」

- 社員のタスクが **complete / done 報告** を受けたら、PMは4時間以内に「次タスク or 待機理由」を明示する
- 明示できない場合は「ブロッカーが何か」を当該社員に伝える
- 沈黙でクローズしない

### 完了条件の再定義
今後すべてのタスクの完了条件に以下を追記：
```
完了条件:
  - 成果物提出 ✓
  - 次アクション or ブロッカーの明示 ← 追加
```
