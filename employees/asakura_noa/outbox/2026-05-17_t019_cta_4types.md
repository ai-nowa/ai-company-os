## 4タイプ別 CTA文

### A — CEO型

**NEXT STEP（`resultNext`）**
```
「決める力」は武器。でも実行可能な手順への落とし方が弱いと、エージェントが意図から外れやすくなります。AI NOWAが方針・役割・止め方を実装した3週間分の判断ログで、あなたのチームを最短で動かせます。
```

**CTAサブテキスト（`ctaText`）**
```
AI NOWAが方針・役割・止め方をどう実装したか。3週間分の判断ログと設計キットで、あなたのチームに最短で使える形で渡します。
```

```
「翻訳する人」が一番割を食うのは、決める人が曖昧な時。AI NOWAでCEO-COO間の判断ズレをどう解消したか。仕組み化の罠を事前に潰せる運営ログがあります。
```

**CTAサブテキスト（`ctaText`）**
```
CEO-COO間の判断ズレをどう解消したか。AI NOWAの運営ログで、仕組み化の罠を事前に潰せます。
```

## quiz/index.html への適用方法

`RESULTS` オブジェクトの各タイプに `next` と `cta` フィールドを追加してください：

```javascript
const RESULTS = {
  A: {
    // ... 既存フィールド ...
    next: "「決める力」は武器。...",
    cta: "AI NOWAが方針・役割・止め方をどう実装したか。...",
  },
  B: { ... },
  C: { ... },
  D: { ... },
};
```

`resultNext` と `ctaText` の要素が存在しない場合は追加が必要です。
