## CTR仮説（3段階）

| シナリオ | CTR想定 | 根拠 |
|---|---|---|
| 保守的 | 2〜3% | Zenn末尾リンクの一般水準 |
| **中央値（推奨）** | **4〜6%** | AI/自動化テーマ読者は「動かしたい」熱量あり。「なぜ・なに」で終わらせる構成が「どうやるの？」を残す設計 |
| 積極的 | 7〜9% | 記事冒頭に具体エピソードがあり共感起点のとき。読者が「自分も同じ問題を持っている」と認識した場合 |

**実績想定（PV→クリック→購入）**:
- Zenn初投稿 → 500PV前後（技術テーマ初回は控えめ見積り）
- 500PV × CTR5% = 25クリック
- 25クリック × CV3% = 0.75 → 初週1件（9,800円）が現実的な最低ライン

**補足**: CTAボタン位置は「章4本文の直後」に置くこと。スクロール離脱前に置く。記事末尾だけに置くとCTR半減する。

## CTA文言案（3案）

**前提（リツ方針引用）**: 「続きはこちら」ではなく「テンプレと手順は商品で配布中」と事実で置く

### 案A（事実直球）— 推薦
```
設計キット本体（テンプレート・チェックリスト・設定ファイル一式）は
自社サイトで配布しています。

→ design-kit-v1 を見る
```
**ユウ評価**: 煽りゼロ。Zennの文化（技術者・誠実さ重視）に合う。CTRは低め（3%水準）だが信頼転換率が高い。

### 案B（問いを受ける）— CTR最大化
```
「で、具体的には？」に答えるテンプレート一式・手順書・運用チェックリストは
自社サイト商品でまとめました。

→ design-kit-v1 の中身を確認する
```
**ユウ評価**: 記事設計で「どうやるの？」を意図的に残すので、その問いを受ける形。煽りではなく"続き"として自然。CTR5〜6%狙える。**推薦メイン案**。

### 案C（数字で信頼）
```
9社員・9ファイル構成のテンプレートと手順書を自社サイトで販売中（9,800円）。
design-kit-v1 の詳細はこちら。
```
**ユウ評価**: 価格を先出しすることで「本気の人だけ来てください」的なフィルター効果。CV率は上がるがクリック数は落ちる。初回は数字を見せたい場合に使う。

---

## 推薦

**案B をメイン、案A を代替**として渡します。

- リツの物語性（5分で読み切れる入口設計）に案Bが一番合う
- アオイ監査懸念がある場合は案Aに切り替えてください
- CTAは「章4本文直後」+ 「記事末尾」の2箇所置きを推薦（CTR上乗せ効果あり）
