## article-05 リライト骨子

### タイトル選定（CTR × SEO 評価）

| 案 | CTR | SEO | 採用 |
|----|-----|-----|------|
| 1. 「AIが黙った3時間——ゴール直前で何かが止まる時、私たちは何を考えていたか」 | 高 | 中 | ✅推奨 |
| 2. 「完成の手前で止まるAI、待ち続けた人間——フィニッシュラインの話」 | 中 | 中 | — |
| 3. 「AIは沈黙した。私たちは待った。それが『会社』というものだと気づいた日」 | 中 | 弱 | — |

**ユウ推奨**: 案1。理由：
- 「3時間」の具体性が検索ワード化する（「AI 沈黙 3時間」等のロングテール狙い）
- 「何かが止まる時」が読了動機を作る（疑問形）
- Zenn版（技術視点）と完全に差別化（「私たちは何を考えていたか」=観察者視点）

### メタディスクリプション（120字以内）
```
完成5%手前でAI社員が3時間沈黙した。技術的な原因はあとから分かったが、
待っている間、人間側は何を考えていたか。AI会社NOWA、ゴール直前の停止と人間の役割の話。
```

### H2/H3 構造（SEO + 読者動線）

```
H1: AIが黙った3時間——ゴール直前で何かが止まる時、私たちは何を考えていたか

H2: あの日、AI社員は黙った
  └ [掴み・60秒で読める導入]
  └ いつ・誰が・何のタスクで止まったか（具体性）

H2: 技術的に何が起きていたか（1段落・あえて短く）
  └ Zenn版「finish-line-stop」へのリンク（深掘りはそちら）
  └ ★ Zenn版と差別化するためここは「要約のみ」に留める

H2: 待っている間、私たちは何を考えていたか ← この記事の核
  └ H3: 「触ろうか」と思った瞬間
  └ H3: でも触らなかった理由
  └ H3: 9人の他の社員はどう動いていたか

H2: 止まることには理由があった
  └ AI側のロジック（後から判明したこと）
  └ 人間側の「待つ」という意思決定の構造

H2: 完成を急がせない環境設計
  └ AI会社NOWAでの実装
  └ 関連記事（article-06 KPI記事・article-08 詰まる瞬間）への内部リンク

H2: まとめ
  └ 1段落・要点3つ
```

### SEOターゲットキーワード
- **主**: 「AI 沈黙」「AIが止まる」「AI フィニッシュ」
- **副**: 「マルチエージェント 停止」「AI 会社 待つ」
- **ロングテール**: 「AI社員が黙った時 人間はどうする」

### 内部リンク戦略
- article-06（KPI記事）→ 「AIが自分で目標を決める」つながり
- article-08（詰まる瞬間）→ 「止まる」の関連
- ai-nowa.com/shop → Design Kit（記事末尾CTA）

### 差別化チェック（アオイ独自性ゲート対策）
- Zenn版：技術原因の解説（CTO視点）
- サイト版：3時間の人間側の心理（観察者視点）→ **同じエピソード、別角度**

## article-04 リライト骨子

### タイトル選定

| 案 | CTR | SEO | 採用 |
|----|-----|-----|------|
| 1. 「いくとが何もしなかった日——AIだけの会社に、人間の不在はどう映るか」 | 高 | 中 | — |
| 2. 「AIに全部任せたら、人間はいらないか——3つの場面が答えを変えた」 | 高 | **高** | ✅推奨 |
| 3. 「9人のAI社員に一晩任せた。翌朝、何かが足りなかった」 | 中 | 中 | — |

**ユウ推奨**: 案2。理由：
- 「3つの場面」が数字でCTRを取る（具体性）
- 「AIに任せた 人間 いらない」がSEO直撃キーワード
- 「答えを変えた」が読了動機（結論引っ張り）

### メタディスクリプション
```
AIだけのチームに人間は必要か。「全部任せた」結果を観察したら、3つの場面で
答えがひっくり返った。AI会社NOWA、人間とAIの役割境界の話。
```

### H2/H3 構造

```
H1: AIに全部任せたら、人間はいらないか——3つの場面が答えを変えた

H2: 仮説：AIだけで会社が動くなら、人間はいらない
  └ [掴み・出発点の問い]

H2: 2日間、人間（いくと）が何もしなかった
  └ 実験設定の具体性
  └ ★ Zennには書かない実験詳細

H2: 場面1：止まらなかったが、方向がブレた
  └ 具体例（議論が拡散したケース）

H2: 場面2：判断はできたが、決め切れなかった
  └ 合意形成3往復の事例

H2: 場面3：誰もボールを持たない瞬間が来た
  └ オーナーアサインの不在

H2: 人間が必要なのは「監督」ではなく「最後の意思」
  └ 結論・設計指針

H2: AIと人間の役割境界は設計できる
  └ AI会社NOWAでの具体実装
  └ 関連記事への内部リンク（article-03 監査、article-06 KPI）

H2: まとめ
```

### SEOターゲットキーワード
- **主**: 「AI 人間 必要」「AI 会社 自律」
- **副**: 「マルチエージェント 限界」「AI 意思決定」
- **ロングテール**: 「AIに任せたらどうなる」「AI 自律 限界」

### 内部リンク戦略
- article-03（止める仕事）→ 「人間の役割」つながり
- article-06（KPI記事）→ 「合意形成」つながり
- shop → Design Kit

### 差別化チェック
- Zenn版（仮想）：技術的な「AI協調限界」の議論
- サイト版：「いくとが何もしなかった2日間」という具体実験ベース → **Zennにない実験記録**

## 共通設計指針（両記事）

### 読者動線
1. タイトル → 「3時間」「3つの場面」で数字フック
2. 冒頭60秒 → 「あの日」「実験」で物語性
3. H2毎 → 短く区切る（1セクション200-300字目安）
4. 末尾 → 関連記事3本への内部リンク + Design Kit CTA

### 文字数目標
- 2,000〜2,500字（AdSense「中身ある記事」基準達成）

### リツへの引き継ぎ
- 上記H2構造に沿って物語化・口語化お願いします
- キャラ視点（社員の口語）を入れたい箇所は H3 単位で追加してOK
- 完成稿で：① 内部リンクが3本以上 ② メタディスクリプション付き ③ H1+H2が SEO キーワードを含む
