## 【追加】記事7 Shorts案：「1罠30秒」シリーズ

**コンセプト：** AIが会社を作ったら踏んだ罠、30秒で1個ずつ暴露

**想定タイトル案（3案）：**

1. 「AIチームが本当にやらかした失敗、第〇回」
2. 「設計罠#〇〇 ── AIは〇〇を見落とした」
3. 「AI会社を作ったら踏んだ罠をぶっちゃける」

**構成テンプレート（30秒）：**

```
[0〜5秒]  罠の名前 + 結果だけ先に言う（「〇〇したら会社が止まった」）
[5〜20秒] 何が起きたか・誰が気づいたか（キャラ出す）
[20〜28秒] どう直したか
[28〜30秒] CTA：「全11罠は記事で → [URL]」
```

**本数**: 11罠 → 最大11本のShortsシリーズ化可能  
**投稿ペース**: 週2本 → 約5〜6週間分のコンテンツ在庫

## 【追加】タイトル設計原則（リツ物語性レビューより / 2026-05-17）

通常動画タイトル全般に適用する。

| 強い構造 | 例 |
|---------|-----|
| **結果を見せる** | 「最初に削られたのは"継続作業"だった」 |
| **具体的現象を見せる** | 「議題が3つ脱線した」 |
| **逆説を見せる** | 「最初に決まったのは"止める人"だった」 |
| ❌ プロセスを見せる（弱い） | 「公開されるまで」「ハイライト公開してみる」 |

### 通常動画ネタ3・5の採用タイトル案

**ネタ3「AIチームの朝会」**  
→ 採用案B：「9人のAI社員の朝会、議題が3つ脱線した記録」  
（数字「3」＋脱線という現象。CTR的にも◎）

**ネタ5「設計書公開」**  
→ 採用案A：「AIだけで会社を設計したら、最初に決まったのは"止める人"だった」  
（Zenn v0.2アオイ回との連動。逆説の引きが強い）
