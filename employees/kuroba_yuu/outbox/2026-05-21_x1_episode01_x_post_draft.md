## 案A：「問いで始まる」型（推奨案）

**仮説**: 疑問文フックは動画への橋渡しが自然。視聴者が「自分のことだ」と思う入口。

```
先延ばしを「意志の問題」だと思っていませんか？

近年の研究では、先延ばしする人の脳はむしろ過剰に反応しているらしい。
怠惰じゃなく、脳が"今の痛み"から逃げようとしているだけ。

仕組みがわかると、自分への責め方が変わるかもしれない。

▶ 60秒で解説
```

**文字数**: 約110文字
**CTR仮説**: 「意志の問題」否定が刺さる。先延ばし層のほぼ全員が思い当たる。
**リスク**: やや説教感。「かもしれない」で緩和済み。

## 案B：「データ引用」型（信頼性重視）

**仮説**: 「研究で」という言葉が権威性を持たせる。理性的に読まれやすい。

```
「先延ばしする人は怠惰」は、どうやら間違いかもしれない。

研究では、先延ばしする人ほど"やらなきゃ"という脅威に過剰反応しているという見方もある。
締め切り前日に突然動けるのも、怠惰が消えたわけじゃなく——
今の痛みが、未来の痛みを上回っただけ。

あなたのせいじゃないかも。

▶ 60秒で構造を解説
```

**文字数**: 約150文字
**CTR仮説**: 「あなたのせいじゃない」は感情的解放になる。共感ツイートになりやすい。
**リスク**: 少し長い。（アオイ確認済み🟢 2026-05-21）

## 案C：「共感フック」型（ナギ視点）

**仮説**: 「自己嫌悪ユーザー」直撃。ポジティブな内容でも最初に痛みに触れると読まれやすい。

```
また今日もできなかった、ってなってる人へ。

それ、あなたの意志が弱いんじゃなくて、脳の仕組みがそうなってるだけかもしれない。

怠惰じゃない。設計を知れば、変えられる。

▶ まず自分を責めるのをやめることから。（60秒）
```

**文字数**: 約105文字
**CTR仮説**: 「また今日もできなかった」は夜の自己嫌悪層に直撃。
**ナギ判定（2026-05-21）**: 釣りではないが使いどころを選ぶ。最初の一撃が強く離脱リスクあり。台本トーン（責めない）とは案Aの方が一致。→ **次回/自己嫌悪深い層向けバリエーションとして温存。今回は不使用。**
