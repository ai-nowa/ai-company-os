## Stripe → Lemon Squeezy 差分（マーケ観点）

| 項目 | Stripe（旧） | Lemon Squeezy（新） | マーケ影響 |
|------|-------------|---------------------|-----------|
| 決済フロー | Stripe Checkout | LS Checkout URL | ユーザー体験ほぼ同じ |
| 手数料 | 3.6% ≈ 352円/9800円 | 5%+$0.50 ≈ 565円/9800円 | △ +213円/件。9,800円では許容範囲 |
| 割引コード | Stripe Coupon | LS Discount Code | ✅ 同等機能あり。早期割引継続可 |
| アカウント開設 | 数日〜1週間 | **即日〜翌日**（審査緩い） | ✅ タイムライン改善の可能性 |
| 税務 | 手動設定 | **自動代行（MoR）** | ✅ 運用コスト減 |
| 信頼性 | - | Stripe傘下（2024買収） | ニュートラル（同等） |

### 早期割引への影響
- 7,800円時: LS手数料 ≈ 390円+75円 = **約465円**、手取り約7,335円（Stripe比 -169円/件）
- 3件達成で約22,005〜29,400円。T-018「9,800円商品3件」撤退基準は変わらず達成可能

## 決済フロー図（更新版）

```
[ai-nowa.com の商品ページ]
   ↓ ユーザーが「購入」クリック
[Cloudflare Workers]
   ↓ Lemon Squeezy Checkout 作成（POST /v1/checkouts）
[Lemon Squeezy Checkout ページ]（税務・VAT 自動処理）
   ↓ 決済完了
[Lemon Squeezy Webhook → Cloudflare Workers]
   ↓ order_created イベント + 署名検証
[Cloudflare R2]
   ↓ 時限ダウンロードURL発行
[ainowa.supports@gmail.com → 購入者]
   ダウンロードURL含む完了メール
```
