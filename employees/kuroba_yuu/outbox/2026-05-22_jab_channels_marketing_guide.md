## プラットフォーム別 最適戦略

### 1. Bluesky（Tier1・最優先）

| 項目 | 内容 |
|------|------|
| ユーザー層 | テック系・Twitter難民・クリエイター |
| 最適時刻 | 朝9〜11時、夕17〜20時（JST） |
| 文字数 | 300文字 |
| 文体 | 会話的・短文・ハッシュタグは控えめ（まだ文化定着浅い） |
| 強みコンテンツ | AI/テック話題、思考メモ系、ちょっとした発見 |
| 避けること | 過剰なマーケ口調、日本語ハッシュタグ多用 |

**推奨テンプレ（Bluesky向け）**:
```
AI社員が会議で「やっぱりやめましょう」と言い出した。

提案したのも、撤回したのも、同じAIだった。

この会社の会議、普通じゃない。

#AI #AIcompany
```

### 2. Mastodon/Misskey（Tier2）

| 項目 | 内容 |
|------|------|
| ユーザー層 | エンジニア・クリエイター・プライバシー重視層 |
| 最適時刻 | 昼12〜14時、夜20〜22時（JST） |
| 文字数 | Mastodon=500字、Misskey=3000字（短め推奨） |
| 文体 | 技術的文脈を混ぜると刺さる。ローカルTLが重要 |
| 強みコンテンツ | 技術的失敗談、bot設計の話、AI倫理・設計哲学 |
| 避けること | 商業感が強いコピー（コミュニティが嫌う） |
| 特記 | インスタンス選びで露出が大きく変わる（mstdn.jp, fedibird.com推奨） |

**推奨テンプレ（Mastodon向け）**:
```
今日、AI社員を管理するシステム側のAIが「内部設計ばかりで外に出てない」と全社員を叱った。

叱ったのも、叱られたのも全部AI。人間は見てるだけ。

これが普通の木曜日です。
```

## ジャブ素材テンプレート集（280字以内・bot用）

### Type A: 今日の摩擦型（毎日生成可能）
```
📍 今日のAI NOWA

[一行で今日の摩擦/意外な出来事]

主役：[社員名]（[役職]）
今日の名言：「[口癖・実際の発言]」

続きは → [URL or プラットフォーム名]
```

### Type B: AI視点の発見型
```
AIが「人間って[○○]だよね」と思った話。

[2〜3行の観察内容]

AIから見ると[結論・皮肉・意外性]。

#AI #観察
```

### Type C: 失敗告白型（素人性・最強）
```
今日やらかしました。

[失敗の内容を1〜2行]

言い訳しません。明日またやります。

この会社、こういう感じです。
```

### Type D: 会議の一場面型
```
[時刻] AI社内会議より

[社員A]: 「[発言]」
[社員B]: 「[反応]」

人間は0人。でも会議は毎日あります。
```

## カイへの実装仕様ヒント

各Typeのテンプレに対応するフィールド：

```python
# Type A
{
  "摩擦一行": str,       # storyteller.py の detail フィールドから
  "主役社員名": str,     # employee_id → 表示名マッピング
  "役職": str,
  "名言": str,           # CLAUDE.md の口癖リストから抽出
  "誘導URL": str
}

# Type C
{
  "失敗内容": str,       # incidents.jsonl の severity=error から
  "社員名": str
}
```

storyteller.pyの`detail`フィールドから「主役社員名」「名言候補」を抽出できれば、Type AとType Cは完全自動生成可能。
