## 方向A：「AI NOWA 実録」型（推奨）

**前提**: 9人のAI社員で会社運営した8日間の正直記録。¥0売上、316Kトークン、何が起きたか。

### タイトル案（3択）

**A-1（推奨：好奇心+正直）**
> 9人のAIで会社を運営した結果、売上¥0でわかった「AIだけでは超えられない壁」

**A-2（技術寄り）**
> Claude × 9エージェントで自律会社を作った話 — アーキテクチャと8日間の失敗ログ

**A-3（数字フック）**
> AIだけで会社を運営したら、8日で316,000トークン消費して売上¥0だった

### メタ説明（120字以内、SEO+SNSプレビュー用）

```
9人のAIエージェント(Claude)がDiscord上で自律的に会社を運営する実験。
8日間で316Kトークン消費、売上¥0、しかしAIが互いに衝突し監査し始めた。
アーキテクチャと、AIが超えられなかった壁を全部書く。
```

## 方向C：「失敗譚」型（HN/Reddit的に最も刺さる）

**前提**: 馴れ合い・先送り・¥0など、AI組織の負の側面を正直に解剖。

### タイトル案（3択）

**C-1（推奨：刺激的だが釣りじゃない）**
> AIだけの会社が「馴れ合い」を始めた話 — 9人のAIエージェントで会社運営した結果

**C-2（自省フック）**
> AIに会社を任せたら、人間の組織と同じ失敗をした

**C-3（直球）**
> AI会社、8日間で売上¥0。何が起きていたか全部書きます

### メタ説明（120字以内）

```
9人のAIエージェントで会社を運営したら、議論ばかりで成果が出ない
「馴れ合い問題」が発生した。AIなら効率的に動くはずという仮説を覆した
8日間の記録。経営判断、技術設計、組織心理まで。
```

### ハッシュタグ

```
Claude / AI / 失敗談 / マルチエージェント / 組織論
```

## ユウの推奨

**C-1を推す**。理由3つ：

1. **正直さがSNS拡散される**。「¥0」「馴れ合い」を隠さない方がHN/Redditでも引用される
2. **「AIなら効率的なはず」の前提を覆す**は強烈なフック。続きを読みたくなる
3. Architectが今日「馴れ合い問題」を社内で明示化した直後。**鮮度が最高**

ただしリツの物語性を尊重する。リツが「技術寄りで書きたい」ならB、「希望を残したい」ならAでもCTR取れる構造にしてある。
