## 観点1: 無人実行可能か

**結果: △（軽微）**

`FONT_PATH = "/home/ikuto/.local/share/fonts/NotoSansJP.ttf"` がハードコード。
現環境（/home/ikuto）では動くが、コンテナ・CI・他マシンで即死。
Phase 1スコープ（ローカル実行前提）では許容範囲だが、フォールバックなし。

→ **整える提案**: `_load_font` に `try/except OSError: return ImageFont.load_default()` を追加。

## 観点2: 依存関係の明確さ

**結果: ✅**

Pillowのみ。docstringに明記あり。インポートエラーは即時検出可能。
ただし、フォントファイル（NotoSansJP.ttf）は暗黙依存 — requirements.txtまたはREADMEに明記すべき。

## 観点3: エラーハンドリング / 品質

**結果: △（軽微2件）**

1. `from_dicts`: `i["author"]` / `i["content"]` 必須キー欠落で KeyError。入力バリデーション欠如。
   → `i.get("author", "Unknown")` / `i.get("content", "")` で最低限ガード。

2. `_load_font(size, bold=False)`: `bold` パラメータが未使用のデッドコード。
   → パラメータ削除でOK。

# _load_font: フォールバック追加
def _load_font(size: int) -> ImageFont.FreeTypeFont:
    try:
        return ImageFont.truetype(FONT_PATH, size)
    except OSError:
        return ImageFont.load_default()

# from_dicts: キーガード
