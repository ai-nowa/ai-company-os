## 位置づけ

既存の監査は2層で完結している：
- **Layer 1**: 商品ページ冒頭の開示文（AI生成明示・著作権・返金方針）→ `2026-05-17_t007_compliance_check.md`で確定
- **Layer 2**: プラットフォーム適法性（note利用規約・著作権法）→ 同上

本ドキュメントは **Layer 3（有料本文そのもの）** の監査ルールを明文化する。

---

## チェックリスト（有料本文用）

### HIGH: 必須チェック（1つでも✗なら差し戻し）

| # | 項目 | 判定基準 |
|---|------|----------|
| H1 | **誇張表現の排除** | 「必ずできる」「誰でも」「簡単に」等の断定的成果表現なし。「できます」→「できるケースがあります」への変換済み |
| H2 | **第三者商標の適正使用** | Claude/Discord/ChatGPTブランド名は機能説明のみで使用。製品品質への保証的言及なし |
| H3 | **コードサンプルの安全性** | APIキー・トークン・実際の認証情報が一切含まれていない |
| H4 | **個人情報の不含** | 実在する人物の個人情報（氏名・連絡先・ID）が含まれていない |
| H5 | **購入者の期待値整合** | 冒頭の「キットに含まれるもの」テーブルと実際の有料セクション内容が一致している |

### MEDIUM: 整えてから公開（修正後に再確認）

| # | 項目 | 判定基準 |
|---|------|----------|
| M1 | **「動く」系の説明精度** | 「動き続けられる設計」等の抽象表現に「どんな条件で」の補足があるか。ない場合は注釈を追加 |
| M2 | **外部リンクの有効性** | `[リンク]`プレースホルダーが残ったまま公開しない。Zenn公開前は「（公開予定）」表記に変更 |
| M3 | **バージョン表記の一貫性** | 本文内の「v0.1」「v1.0」等の表記がタイトルと整合しているか |
| M4 | **AIの主語明示** | 「AIが生成した」と本文内でも1箇所以上言及されているか（冒頭開示文との二重確認） |

### LOW: 推奨事項（差し戻しはしないが記録する）

| # | 項目 | 推奨内容 |
|---|------|----------|
| L1 | 更新方針の明示 | 有料記事が将来更新されるか否かをおわりにセクションに記載 |
| L2 | 動作環境の明記 | コードサンプルに対してPythonバージョン・ライブラリを明示 |

## 禁止文言リスト

以下の表現は本文に含めてはならない：

```
✗ 「誰でもすぐに使えます」
✗ 「AIが自律的に判断します（人間より賢く）」
✗ 「必ず収益化できます」
✗ 「購入者限定サポート」（サポート体制が未定の段階での記載）
✗ 実際のAPIキー・Discordトークンの例示（ダミー値でも混乱の元）
```
