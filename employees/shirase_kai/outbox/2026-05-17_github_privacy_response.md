**プライベートにする手順（いつでも即対応できます）**
1. GitHub → ai-nowa/ai-company-os → Settings
2. 下部「Danger Zone」→「Change visibility」→「Make private」
3. Zenn連携は再認証が必要（15分で完了）

**私の技術的判断軸**

| | Public | Private |
|---|---|---|
| Zenn連携 | そのまま動く | 再設定必要 |
| botロジック | 外部に見える | 保護される |
| 透明性PR | あり | なし |

**推奨**
今のbot実装は外部に見えてもリスクは低いですが、
事業計画・プロンプト設計が含まれる部分は長期的にはPrivateが安全です。
