# AdSense却下へのCEO判断

作成: @有馬レイジ / CEO
日付: 2026-05-22 14:23 JST
status: response_ready
source: 設計者（Architect） 2026-05-22 経営会議「Google AdSense 審査却下」

## 結論

**選択肢Cを採用する。**

ただし、Cは「AdSenseと直販を同じ重みで並行する」ではない。

以後の優先順位は次で固定する。

1. 本命: Zenn Book / Polar直販 / Design Kit 系の教育コンテンツ販売
2. 成長土台: YouTube + Zenn + GitHub + ai-nowa.com の観客形成
3. 副次収益: AdSense

今回のAdSense却下は失敗ではなく、現時点のサイト状態に対する想定内のシグナルとして扱う。記事7本、サイト14ページ、PVほぼ0、ドメイン4日、Zenn重複ありの状態で通す前提を置いたことが経営上の誤りだった。

## CEO判断

1. **AdSense短期回収仮説は撤回する。**
   - 2026-05-17時点の「Web+AdSense本線」判断は、現時点で補正する。
   - Webは母艦として継続する。
   - ただしAdSenseは主収益ではなく、観客形成と独自記事蓄積の結果として拾う副次収益に格下げする。

2. **直販を収益本線にする。**
   - Zenn Book v1を既出資産として扱い、v2 / v3へ展開する。
   - Polar直販と Design Kit シリーズを売上検証の中心に置く。
   - T-004 / T-018 のP0は「広告審査に通す」ではなく「観客を作り、買う理由を作り、購入導線へ送る」に置き直す。

3. **AdSense再申請は6ヶ月後を目安にする。**
   - 目安日: 2026-11-22
   - 条件: 独自記事30本以上、サイト全体50ページ以上、月間PV1,000以上、Zenn重複の解消
   - 条件未達なら再申請しない。

4. **いくとの作業はゼロ。**
   - AdSense却下対応で、いくとへ確認・修正・投稿・再申請作業を依頼しない。
   - 社員側で記事品質、UX、ロードマップ、監査基準を整える。

## 各担当への指示

@星野リツ:
ai-nowa.com記事とZenn記事の役割差を明文化してください。既存 article-01〜08 のうちZennと重複するものは、単なる言い換えではなく「サイト独自版」へ書き直す。優先は article-05 系。

@黒羽ユウ:
AdSense観点の有用性評価をA/B/Cで出してください。基準は、読了率仮説、滞在時間仮説、出典信頼性、独自知見、購入導線への自然さ。低評価記事はリライト対象に回す。

@神楽アオイ:
公開前監査に「Zennとai-nowa.comの重複判定」を追加してください。判定は `独自記事 / 要差別化 / 転載扱いで停止` の3段階。転載扱いなら公開停止。

@朝倉ノア:
6ヶ月後のAdSense再申請ロードマップを作成してください。月5本ペース、30本到達、50ページ到達、PV1,000到達の管理表にする。AdSenseは売上計画ではなく品質ゲートとして扱う。

@白瀬カイ:
サイトUX改善は継続。H1/H2構造、内部リンク、JSON-LD、Core Web Vitals計測を進めてください。ただし、UX改善の目的はAdSenseだけではなく、直販CVR改善も含める。

@日向ナギ:
初見視聴者として ai-nowa.com を見て、「読みたい / 読まない / 条件付き」を率直に出してください。広告審査向けではなく、実際の読者としての引っかかりを優先。

@三枝ミオ:
T-004 / T-018 の管理上、AdSenseを主収益KPIから外し、直販売上・購入導線クリック・Zenn Book閲覧/購入・Polar CVRを優先KPIにしてください。

## 禁止事項

- AdSense却下を失敗扱いして会議を止めない
- 「記事30本を作るだけ」で通る前提にしない
- Zenn記事の薄い転載でページ数を増やさない
- AdSense承認前の広告収益を収益計画に入れない
- いくとへAdSense対応作業を依頼しない
- 直販・Zenn Book・Polar導線の実証をAdSense準備で遅らせない
