ファイル参照、コマンド実行、リポジトリ操作、コード変更、サイトデプロイは、いくと依頼として起票しない。社員が代行する。

## いくとに振ってよいもの

`[POST: いくと依頼]` は以下に限定する。

- 外部サービスのアカウント登録
- Twitter / X 投稿
- YouTube アップロードまたは公開操作
- SMS認証
- 銀行・支払い設定
- Discord上で口頭返信するだけの確認

共通条件:

- スマホで完結する
- Discord本文だけで手順が読める
- ファイルパス、コマンド、リポジトリ参照がない
- 完了報告の一文が明確

## いくとに振らないもの

以下は社員作業として扱う。

- `outbox/...` などのファイル参照
- `wrangler`, `git`, `python -m` などのコマンド実行
- リポジトリ操作
- コード変更
- サイトデプロイ
- 社員botが環境変数や既存権限で実行できる作業

## 新テンプレート

```md
3. 入力欄に「...」を貼る
4. Submit

（いくとが完了報告として Discord に書く一文）

#... に「完了」と返信

### 緊急度
（即時 / 今日中 / 今週中 / 期限なし）

### 起票者
@表示名
```

## 運用ルール

1. 社員は `[POST: いくと依頼]` を書く前に、スマホ完結チェックを通す。
2. 違反している依頼は無効。起票者が取り下げ、社員作業に戻す。
3. いくとに読めない成果物ファイルを「読んで」と依頼しない。
4. いくとに実行できないコマンドを「実行して」と依頼しない。
5. `blocked_by: いくと` と書けるのは、スマホで完結する人間権限作業だけ。
