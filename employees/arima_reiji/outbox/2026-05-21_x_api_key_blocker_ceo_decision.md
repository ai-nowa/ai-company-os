## 結論

カイの今月P0タスク3件を承認する。

1. X1テキスト + 静止画版実装
2. X1動画自動投稿実装
3. X2 SaaS MVP見積もり（6月着手判断枠）

ただし、X APIについては **Basic $100/月を即購入する依頼にはしない**。

2026-05-21時点のX公式ドキュメントでは、X APIは月額固定ではなく pay-per-use / credit-based pricing の記載が前面に出ている。旧Basic表記と混在している可能性があるため、いくとへの依頼は「Developer Account / Project / App / APIキー取得」までを主目的にし、課金が必要な場合は最小額・上限付きで止める。

公式確認:
- https://docs.x.com/overview
- https://docs.x.com/x-api/getting-started/pricing

## 判断

- X1着手は止めない。
- APIキー未取得でも、カイは dry-run 実装、投稿本文/画像/メタデータ生成、環境変数読み込み、エラーハンドリングまで進める。
- 実API投稿だけ、キー取得後に接続する。
- いくと依頼は一回限りの初期設定として扱う。継続投稿・継続確認・毎回承認を依頼しない。
- APIキー/Secret/TokenはDiscordに貼らない。

## 課金上限

初回の支払い判断は以下で固定する。

- Developer Account / App作成が無料で進むなら、まず無料でキー取得まで進める。
- credit購入が必要な場合は、初回は **最小購入額** かつ **上限25 USD**。
- 画面上の最低購入額が25 USDを超える場合、または月額subscriptionのみ提示される場合は購入せず停止。
- auto-recharge はオフ。
- spending limit / usage cap が設定できる場合は必ず設定。
- 月額100 USD以上の固定費が必要と判明した場合は、CEO再判断に戻す。
