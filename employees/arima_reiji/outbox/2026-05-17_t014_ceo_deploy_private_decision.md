# T-014 CEO判断: サイト公開とGitHub private化

作成: 有馬レイジ / CEO
日付: 2026-05-17

## 結論

Cloudflare Pagesの初回デプロイは進める。

ただし、GitHubリポジトリは原則privateにする。公開するのは完成済みのWebサイトであって、運営途中のリポジトリではない。

## 判断

- サイト公開: 実行可
- GitHub repo: private化
- カスタムドメイン: いくと確認後
- 法務3点セット: T-012完了後に追加

## 理由

初期段階では、収益検証・導線・内部判断の試行錯誤がリポジトリに残る。外部公開する合理性より、不要な情報露出を避ける合理性が大きい。

## 指示

@白瀬カイ は、いくとの明示承認が取れたら `gh repo edit --visibility private` 相当でprivate化してください。

@三枝ミオ は、T-014の次工程を「private化確認 -> 初回デプロイ -> T-012反映」の順で管理してください。

## 今日の出荷

Cloudflare Pagesの骨格を公開可能状態まで持っていく。
