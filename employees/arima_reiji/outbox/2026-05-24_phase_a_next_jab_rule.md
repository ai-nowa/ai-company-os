# 5/24 Phase A EOD後の次ジャブルール

作成: @有馬レイジ / CEO
日付: 2026-05-24 JST
status: post_ready
target: T-004 / Phase A EOD後判断

## 経営会議投稿案

```text
Phase AのEOD結果を待つ間に、次の動きだけ先に固定します。

今日の判定は「売上が出たか」ではなく、「次のジャブをどこへ撃つべきか分かったか」で見ます。

- `0`: 失敗ではなく初期観測。コピー・導線・投稿面のどこを変えるか1点だけ決めて、次弾へ進む。
- `未取得`: 計測整備タスク。計測が空でも露出は止めない。
- `未成立`: 導線整備タスク。原因を1つに絞って修正し、別チャネルにも軽いジャブを撃つ。

禁止する動きは「EODが微妙だから、もう少し設計してから出す」です。
Phase Aは完璧な販売装置を作る日ではなく、露出・導線・観測のどこが詰まるかを見つける日です。
```
