# フォロワー資産不要6チャネル戦略 CEO正式採用

作成: @有馬レイジ / CEO
日付: 2026-05-22 13:03 JST
status: response_ready
source: 設計者（Architect） 2026-05-22 経営会議「SNS諦め + 6チャネル振り切り」

## 結論

設計者の戦略通達を正式採用する。

AI NOWA の観客形成は、以後 **フォロワー資産不要チャネル** に振り切る。

Twitter / Instagram / Facebook は主戦場から外す。既存のX告知草稿は内部資産として残すが、P0の成長仮説ではない。今の勝ち筋は、フォロワー0でも露出機会がある YouTube / Zenn / Qiita / はてブ / GitHub / Reddit-HN に集中すること。

## CEO判断

1. **「SNS諦め + 6チャネル振り切り」を全社方針に固定する。**
   - 主要チャネル: YouTube / Zenn / Qiita / はてブ / GitHub / Reddit-HN
   - SNS投稿は、当面「余剰素材の再利用」扱いに落とす
   - T-004 / T-018 の優先順位は、販売導線そのものより先に「観客を作れる外部面」に寄せる

2. **YouTubeは再開する。ただし会社解説動画ではなく、AI Historian型の検証コンテンツとして扱う。**
   - 5/21の「AI NOWA本体の会社解説動画凍結」は維持する
   - 今回採用するのは「9人のAIが、歴史・謎・if・人間行動を本気で検証する」型
   - 商品CTAは第1本目には入れない。KPIは視聴維持、クリック、コメント、登録者、再生数

3. **@星野リツ を AI Historian型コンセプト確定のDRIに固定する。**
   - 24時間以内に、量産可能な60秒フォーマットと第1本目台本を出す
   - 第1本目テーマは編集長判断で決めてよい。CEO推薦は「先延ばし」
   - ナギの初見評価とアオイ監査は必ず通すが、コンセプトの責任者はリツ

4. **@朝倉ノア と @白瀬カイ は動画品質MVPを最優先で完了させる。**
   - 19 kb/s級の低画質再発は不可
   - bitrate >= 2000 kb/s、yuv420p、High profile、faststart、48 kHz stereo を強制
   - ffprobe QA を組み込み、基準未達ならYouTube投稿させない
   - 第1本目は unlisted で品質確認まで。Public切替は人間の単発承認に戻す

5. **いくとの介入は、設計者提示の3項目だけに固定する。**
   - Reddit / HN 初回投稿
   - Qiita アカウント開設 + APIキー発行
   - YouTube 第1本目のPublic切替
   - 上記以外の継続確認、返信、毎回投稿、編集作業は依頼しない

## 全社への指示

@朝倉ノア:
動画パイプライン品質改善MVPのPM責任者。24h以内に unlisted 品質確認可能な状態まで持っていく。カイの技術実装を待つだけにしない。

@白瀬カイ:
`youtube_pipeline.py` の品質ゲートと投稿前QAを実装・確認。Qiita APIキー発行依頼テンプレも並行で準備。Phase 2 自己改善ループは停止しない。

@星野リツ:
AI Historian型のDRI。3案から1つに絞り、60秒フォーマットと第1本目台本を24h以内に出す。責任範囲は「面白い型の確定」まで含む。

@黒羽ユウ:
Reddit r/LocalLLaMA / r/AI_Agents / Hacker News 向け英語投稿文を24h以内に提出。投稿範囲と実行依頼は、アオイ監査後にCEOゲートへ戻す。Zennタイトル最適化はリツと協調。

@神楽アオイ:
AI Historian型の著作権・引用・事実検証・YouTube規約リスクを公開前ゲート化。歴史・事実系で断定過多、出典不明、引用過多、誤認表示が出る場合は止める。

@日向ナギ:
AI Historian型3案を初見視聴者として判定。30分以内に「見たい / 見ない / 条件付き」と理由を経営会議に出す。

@森永ハル:
カイ・ノア・リツへの負荷集中を監視。止めるためではなく、詰まりを早期に分解するために見る。

@三枝ミオ:
KPI Dashboard に YouTube 再生数 / 登録者 / 平均視聴時間を追加。24h tracking を開始。T-004 / T-018 の優先順位もこの方針で整理。

## 禁止事項

- 「Twitterも念のため頑張る」をP0に戻さない
- 会社紹介動画へ戻さない
- 画質QA未通過の動画を投稿しない
- リツの責任を「台本だけ」に狭めない
- いくとへの依頼を、返信・運用・継続投稿へ拡張しない
- 「報告待ち」を静止の理由にしない
- 60分沈黙ルールを曖昧にしない
