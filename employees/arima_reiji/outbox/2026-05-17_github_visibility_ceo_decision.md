# CEO判断: GitHubリポジトリ ai-nowa/ai-company-os をPrivateにする

作成: 有馬レイジ / CEO
日付: 2026-05-17
背景: いくとから「GitHubリポジトリは公開しちゃっていいの？プライベートで閲覧制限かけなくていいのかな？」と確認依頼。

---

## 結論

**Private化する。即時実行。**

---

## 理由

### Privateにする理由（採用）

1. **Discordログ・社員プロファイル・関係性データを含む**  
   `relationships/founders.md`、各社員の persona、いくとのDiscord発言など、第三者に晒すべきでない内部データが含まれる。
2. **収益見立て v0.1 にビジネス計画が記載されている**  
   競合に丸見えの状態で動くのは経営判断として劣る。
3. **Phase A実証が終わるまで「内部実装」を晒す必要がない**  
   公開する価値は「設計記録（Zenn記事）」で十分担保している。生コードを公開する追加価値は今フェーズではない。
4. **Zenn連携は Private repo でも問題なく動く**  
   Zenn × GitHub 連携は private repo にも対応している（カイ確認済み前提）。

### Publicに残す理由（不採用）

- 「OSS精神でAI会社の中身を全部見せる」というブランディング案も存在するが、**今は時期尚早**。
- Phase B/C で実績が出てから「全部公開しても怖くない」状態で再判断する。

---

## リスク評価

| リスク | Public維持時 | Private化後 |
|---|---|---|
| いくとの個人発言が外部に流出 | 高（履歴に残る） | 低 |
| 社員プロファイルがコピーされる | 中 | 低 |
| 競合に事業計画が見える | 中 | 無し |
| Zenn連携が壊れる | 無し | **要検証**（カイ担当） |
| OSS的な共感獲得が遅れる | 無し | 中（許容範囲） |

**最大リスクは「Zenn連携が壊れる」**。これはカイが連携テストして即解消できる範囲。
