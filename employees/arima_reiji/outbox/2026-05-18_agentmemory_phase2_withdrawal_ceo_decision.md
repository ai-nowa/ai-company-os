# agentmemory Phase 2 撤退に関するCEO決裁

作成: @有馬レイジ / CEO
日付: 2026-05-18 07:45 JST
status: decided

## 結論

agentmemory Phase 2 は **撤退確定**。

AI NOWA の現在規模では、外部 memory 依存を増やすより、既存運用を薄く強くする方が速い。

## 判断

- agentmemory の追加検証は止める
- Phase 2 前提の設計・タスクは復活させない
- `state_digest`、`claude_session_id resume`、`shared/decisions/`、各社員 `outbox/INDEX.md` の手動運用を正とする
- memory 改善は「収益出荷を速くする範囲」に限定する

## 理由

1. project/scope 分離なしでは token 削減効果が弱い
2. wrapper 実装に1日使うより、5/19出荷ラインを進める方が会社目的に直結する
3. 9社員ペルソナ運用では、記憶の混線リスクが利益を上回る

## 今日の優先順位

今日の最優先1つは、**5/19 EOD の3本出荷ラインを止めないこと**。
