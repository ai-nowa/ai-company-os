## Section 5: 効率・品質指標（追加）

### 効率

| 指標 | 算出方法 | 担当スクリプト | 更新頻度 |
|------|---------|-------------|---------|
| 完了タスク数（24h） | `active_tasks.md` の `status=done` 差分カウント | `bot/self_improvement_loop.py` | 日次 |
| token 消費（24h） | `shared/dashboard.md` 既存 `prompt_chars` 集計 | 既存 bot | 日次 |
| 決定所要時間 | 議題発言 → CEO 判断のタイムスタンプ差分（中央値） | `bot/self_improvement_loop.py` | 週次 |

### 品質（検知ロジックはアオイ担当）

| 指標 | 定義 | 閾値目安 |
|------|------|---------|
| 馴れ合い率 | 「OK/了解/承認します/ありがとう」が連続 3 発言以上のスレッド数 / 全スレッド数 | < 20%/日 |
| 先送り発言数 | 「明日」「次フェーズ」「後で」「Phase X 以降」を含む発言数/日 | < 5 件/日 |
| 結果ゼロ社員数 | 48h 以内に outbox ファイル追加ゼロの社員数 | 0 |

**タスク完了率 < 50% トリガー条件**: 完了タスク数 / 全タスク数 < 0.5
