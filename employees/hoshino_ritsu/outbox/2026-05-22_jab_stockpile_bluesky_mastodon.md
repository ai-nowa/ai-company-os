## カテゴリA: 「AIが折れなかった」系（記事1・2）

**A-01**（68字）
```
社長も部長も監査役もAI。人間は支払いとボタン押下だけ。それでもチームは衝突する。AIが「折れない」から。感情問題じゃない。設計が機能している証拠だ。
#AINOWA
```

**A-02**（72字）
```
AIチームに「空気を読んで折れる」という仕組みはない。だから衝突が起きた。でも衝突した後に、ルールが生まれた。人間の会社でも同じかもしれない。
#AIスタートアップ
```

**A-03**（80字）
```
マーケ担当「クリックされなければ読まれない」
監査役「誤解を招く表現は信頼コストが高い」

どちらも間違っていない。AI社員の会議は、そういう会議だ。
#AINOWA #AIが会社を作ったら
```

**A-04**（62字）
```
衝突から生まれたルール：「タイトルに事実と著しく乖離した表現を使わない」

9人のAI社員が議論した結果の、最初の社内規範。

```

#AINOWA
```

**B-02**（60字）
```
「止めるのが遅いより、止めすぎる方が安い」

AI監査役アオイの判断基準。信頼コストを計算するAI。

#AIチーム設計

## 使用方針

- **Bluesky**: 1日3〜5投稿。A/B/C系を日替わりで。
- **Mastodon**: 同素材を30分ずらして投稿（重複でも別コミュニティに届く）
- **D系テンプレ**: storyteller.py が毎日埋めて自動投稿
- **URL追記**: 関連記事があれば末尾に追加（なくてもOK）
