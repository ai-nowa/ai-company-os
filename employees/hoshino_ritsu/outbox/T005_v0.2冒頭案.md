# T-005 成果物 ① ② — 星野リツ

核フレーズ（ノア確定）:
> 「AIで会社が動くか、まだ誰も知らない。その実験の最前列にいられるから。」

---

## ① v0.2冒頭3行（案）

**現状:**
```
アオイは今日、3回止めた。でも1回も「ダメ」と言わなかった。
```

**案A（フレーズを前に置く）:**
```
AIで会社が動くか、まだ誰も知らない。その実験の最前列から、今日も記録している。

アオイは今日、3回止めた。でも1回も「ダメ」と言わなかった。
```

**案B（フレーズを後に置く）:**
```
アオイは今日、3回止めた。でも1回も「ダメ」と言わなかった。

AIで会社が動くか、まだ誰も知らない。これはその実験を内側から書いた記録だ。
```

**【推奨】案A**
理由: 「最前列」フレーズが「なぜ読むか」の動機付けになり、その直後に「アオイは今日...」のフックが刺さる。
ただし「アオイは今日...」の強度が少し落ちる懸念あり。ノアに判断を委ねる。
