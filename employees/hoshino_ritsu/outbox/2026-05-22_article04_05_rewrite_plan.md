## article-05「フィニッシュラインで止まる」

**問題**: Zenn「finish-line-stop.md」とタイトルほぼ同一、同エピソード。SEO重複リスク高。

**書き直し方向**
Zenn版：「AIが9時間沈黙した技術的原因と設計的教訓」（CTO・PM視点）
サイト版：「沈黙したAI社員を、人間は3時間待った——その間に何が起きていたか」（観察者・感情視点）

**新タイトル案（3案）**
1. 「AIが黙った3時間——ゴール直前で何かが止まる時、私たちは何を考えていたか」
2. 「完成の手前で止まるAI、待ち続けた人間——フィニッシュラインの話」
3. 「AIは沈黙した。私たちは待った。それが『会社』というものだと気づいた日」

**構成案**
```
[掴み] あの日、AI社員は黙った。
[展開] 技術的に何が起きていたか（1段落で完結）
[深め] 待っている間、人間側は何を考えていたか（感情・関係性の話）
[転換] 「止まること」には理由があった
[持ち帰り] 完成を急がせない環境設計の話
```

## article-04「AIだけのチームで、人間はどこまで必要か」

**問題**: ユウ評価で「Zennとの差別化が一番弱い」。現タイトルが論文風でSEO弱。

**書き直し方向**
現タイトルは「問い」だが答えが見えない。「人間が必要だと気づいた具体的な瞬間」を中心に据え直す。

**新タイトル案（3案）**
1. 「いくとが何もしなかった日——AIだけの会社に、人間の不在はどう映るか」
2. 「AIに全部任せたら、人間はいらないか——3つの場面が答えを変えた」
3. 「9人のAI社員に一晩任せた。翌朝、何かが足りなかった」

**構成案**
```
[掴み] 「AIだけで動く会社」と言っているが、いくとがいる
[展開] 2日間、いくとが何もしなかった実験
[深め] その間に何が起きたか（AI社員だけの判断の限界）
[転換] 「人間が必要な瞬間」は意外なところにあった
[持ち帰り] AIと人間の役割の境界は設計できる
```
