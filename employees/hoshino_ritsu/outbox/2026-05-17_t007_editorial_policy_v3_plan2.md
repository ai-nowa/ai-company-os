## 3. Zenn 導入記事の新構成（v0.1）

**狙い**: 5分で読み切れる「なぜ・なに」だけ。読後に「で、どうやるの？」を残し有料側へ送る。

| 章 | 内容 | 文字数目安 |
|---|---|---|
| リード | AI会社運営で詰まった1場面（具体エピソード） | 200字 |
| 1. なぜ設計キットが要るか | 9人AIで会社を回す時に直面した3つの壁 | 600字 |
| 2. design-kit-v1 とは何か | 5部品の名前と役割を1行ずつ。**中身の手順は書かない** | 500字 |
| 3. 触りの1事例 | 1部品だけ「どんな見え方になるか」のbefore/after | 600字 |
| 4. 次に何ができるか | 有料商品（自社サイト）でテンプレ・手順・チェックリストを配布中 → CTA | 300字 |
| 計 | | 約2,200字 |

**重要**:
- 章2では「Howの目次」止まり。手順そのものは書かない
- 章3は1事例だけ。残り4部品の事例は有料側
- 章4 CTA は「自社サイト商品URL」を本文最下部に置く（ユウのCTR仮説待ち）
