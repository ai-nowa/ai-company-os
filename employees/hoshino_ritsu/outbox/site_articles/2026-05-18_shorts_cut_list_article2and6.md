## 記事2 Shorts用 推奨カット（30秒・最優先）

### シーン：「出荷の定義が違った瞬間」

**使う素材（v0.3ドラフト L23〜38 抜粋）**

```
カイの言葉: 「技術的には完了している」
ノアの判断: 「記事が読者に届いていない」
結論（リツ）: 「どっちも正しい。でも2つは別のゲートだ」
```

**構成案（30秒）**:

| 時間 | 映像 | テロップ |
|------|------|---------|
| 0〜3秒 | Discord会議ログの断片（カイ発言） | 「技術的には完了しています」 |
| 3〜8秒 | 別発言（ノア） | 「読者に届いていません」 |
| 8〜12秒 | 無音0.5秒 → 静止 | — |
| 12〜20秒 | テキストスライド | 「どちらも正しかった。でも2つは別の確認だった。」 |
| 20〜30秒 | エンド + テロップ | 「AIチームの衝突設計 → 詳しくはリンクから」 |

**演出メモ**:
- 「VS」感を出さない。どちらも責めない「設計の話」として見せる。
- テロップフォント: 落ち着いた白文字、装飾なし。
- BG音: なし（沈黙がドラマ性を作る）。

## 記事6 Shorts用 推奨カット（記事2とは別角度）

### シーン：「全員が自分の完了に到達していた」

**使う素材（v0.3ドラフト L43〜54 抜粋）**

```
私（リツ）: 「コンテンツとして完成した」
カイ: 「技術的なリスクがある」
ミオ: 「事業設計の制約に抵触」
レイジ: 「今日出す。Zennで」
```

→ 4者が同じものを見て、全員違う「完了」の状態にいた。

**構成案（30秒）**:

| 時間 | 映像 | テロップ |
|------|------|---------|
| 0〜5秒 | 「4人のAI社員が、同じ日、同じものを見た」 | テキストスライド |
| 5〜18秒 | 4者の「完了」を1行ずつ順に表示 | リツ → カイ → ミオ → レイジ |
| 18〜25秒 | 「全員が"終わった"と思っていた。でも会社は止まっていた」 | テキストスライド |
| 25〜30秒 | エンド | 「設計の話はZennで → リンクから」 |

**演出メモ**:
- 記事2の「衝突」より「コミカルなすれ違い」として出す。笑える設計。
- 4者テロップの間に0.5秒の間を入れる（テンポが命）。
