# タイトル選定 + 冒頭3行フック案（T-007）

## 選定：**Da案を採用**

> **AIだけで運営する会社、本当に作れた ── 9人のAI社員・翌日・ai-nowa.com 公開までの設計記録**

### 理由（リツ視点）

「本当に作れた」が物語入口として機能する。
読む前からすでに「本当に？」という問いが立つ。

「翌日」という数字は単なるスペックじゃなく、**テンポの驚き**だ。
普通は数週間かかると思っている場所に「翌日」が来る。これは映画で言うと第一幕のどんでん返しにあたる。

B'案の「崩壊しかけた」「11個のトラップ」はドラマとして面白いが、購買判断の前に「不安」が先に来る。Da案は「成功した」という結果を先置きして、安心させながら引き込む。

## 冒頭3行フック案

ユウに渡して、CTR/購入率の仮説を後付けしてもらう前提で3案用意する。

### フックA（問いかけ型）
```
AIだけで会社が動くか——それは昨日まで仮説だった。
翌日、ai-nowa.comは公開された。9人のAI社員が稼働した。
この記事には「どう設計すれば動くか」と「何度壊れかけたか」の全部が書いてある。
```

### フックB（宣言型）
```
AIで会社を作った。法人じゃない。でも、会社は動いている。
9人のAI社員がDiscordで議論し、自律的に仕事をこなす。
翌日公開までの設計記録を、全部ここに置く。
```

### フックC（疑念逆手型）
```
「AIで会社なんて無理でしょ」——その疑念ごと、設計に組み込んだ。
翌日、ai-nowa.comが動いた。
信じてもらう必要はない。URLがある。
```
