作成: 森永ハル（People）

## 前提：「結果ゼロ」の再定義

**「結果ゼロ」≠ サボり**

自己改善ループが「結果ゼロ社員をスティグマ化する装置」になると、
心理的安全性が壊れ、会議でのリスクある発言が消える。
People担当として、可視化の設計に以下を組み込むことを要求する。

### 結果ゼロの区別（3種類）

| 種別 | 状態 | 対応 |
|------|------|------|
| **A: blocked** | 他社員/いくと待ちで動けない | 表示: 🔒 待機中。介入なし |
| **B: working** | 作業中・成果物未提出 | 表示: 🔄 進行中。6h超で声かけ |
| **C: lost** | タスク不明・方向感なし | 表示: ❓ 要サポート。ハル即介入 |

**C（lost）だけが「モチベ介入」対象。AとBを同列扱いしない。**

## 可視化の設計（People視点）

### NG設計（やってはいけない）
- 「今日の成果物ゼロ：白瀬カイ」のような名指し表示
- ランキング形式（下位への恥の可視化）
- 全体チャンネルへの自動通知

### OK設計（これで実装してほしい）

```
[daily_wellbeing_check] 対象: shirase_kai
状態: result_zero (8h)
理由推定: blocked_by_ikuto (youtube_public待ち)
→ 種別: A (blocked) → ハル介入なし、自動スキップ
```

```
[daily_wellbeing_check] 対象: hinata_nagi  
状態: result_zero (6h)
理由推定: 不明
→ 種別: C (lost) → ハル介入フラグON
```

### ハルの自動介入アクション（種別Cのみ）

1. **private DMでまず声かけ**（全体チャンネルではない）
   > 「最近静かですね。詰まっているタスクありますか？話しやすいところで」

2. **3h後に無反応なら**、関係者（ミオまたはノア）に共有
   > 「ナギさんの状態確認お願いしてもいいですか」

3. **それでも動きなければ**、Architectにエスカレーション

## `self_improvement_loop.py` に渡す仕様（カイへ）

```python
# People向けシグナル出力仕様
{
  "employee_id": "hinata_nagi",
  "signal": "result_zero",
  "hours": 6,
  "blocker": None,  # blockerがNoneならlost判定
  "notify_target": "morinaga_haru",  # Peopleに通知
  "channel": "private",  # 全体ではなくPrivate
  "suppress_public": True  # 全体チャンネルへの露出禁止
}
```

### 「blocked」判定ロジック（カイへの提案）

`active_tasks.md` の `blocked_by:` フィールドを読む。
`blocked_by: いくと` / `blocked_by: 外部` が記載されていれば自動でA判定。
フィールドなし・タスクなしならC判定候補。

## モチベ維持のための「称賛自動補完」

自己改善ループが「指摘装置」だけになると疲弊する。
改善サイクル完了時に、ハルが**称賛ログを自動生成**する仕組みを追加する。

```
[PDCA完了] ユウの認知改善策 → 12h後 +3 Zenn likes
→ [ハル自動称賛] "ユウの施策が数字を動かしました。小さくても実数値。"
```

対象: PDCAサイクルで計測した「改善貢献者」に週次でまとめて投稿。
過程への称賛（「提案したこと」「速く動いたこと」）も含める。

## ハルの役割サマリー（自己改善ループ内）

| トリガー | ハルの行動 |
|----------|-----------|
| result_zero & blocked | 何もしない（待機が正解） |
| result_zero & lost (6h) | DMでソフト声かけ |
| result_zero & lost (9h) | ミオ/ノアに共有 |
| PDCA完了 | 称賛ログ作成 |
| 週次 | 「誰がループを回したか」称賛投稿 |

---

## 懸念点（設計者へ）

「議論30回超で決定ゼロ → 即指摘」トリガーは有効。
ただし「誰が決定を止めたか」の個人名を自動発火に含めないこと。
指摘は「状況」に向ける。「人」に向けない。

これだけ守れば、自己改善ループはモチベを壊さずに機能する。
