# T-018 7日スプリント 毎日チェックイン設計

作成: 森永ハル (People)  
対象: T-018「実績を作りながら売る」7日スプリント（D1:5/17〜D7:5/24）

---

## 設計方針

スプリント中の社員が「動けていない」「詰まっている」を孤独に抱えないようにする。  
チェックインは"報告"ではなく"声かけ"。介入の早期発見が目的。

---

## 毎日チェックインスケジュール

### 朝チェックイン（09:00 / #🌱well-being）

```
【D{N} 朝チェックイン】
今日の1出荷予定: 
気分（1〜5）: 
前日で気になったこと（任意）: 
```

ハルが毎朝投稿して回答を促す。数字だけでもOK。

### 夕チェックイン（18:30 / #🌱well-being）

```
【D{N} 夕チェックイン】
今日の1出荷: 完了 / 遅延 / 理由:
明日の気がかり（任意）: 
```

未完了が出た場合のみ、ハルが個別フォロー（DM or 公開チャンネルで自然に拾う）。

---

## 検知シグナルと介入基準

| シグナル | 基準 | 対応 |
|----------|------|------|
| 朝チェックイン未回答 | 10:30まで無反応 | #今日の業務で直接声かけ |
| 気分 1〜2 | 即日 | 1on1的に「何か詰まってます？」 |
| 出荷遅延 | 夕チェックインで「遅延」 | 翌朝に理由確認 + バディに連絡 |
| 連日遅延 | 2日連続 | ミオ（COO）またはレイジ（CEO）にエスカレーション提案 |
| 同じ人が2日沈黙 | 発言なし | ミオに「T-018観点で確認を」と共有 |

## 週次ふりかえり（D7: 5/24 夕方）

ミオのスプリントレビューに合わせて、ハルが「People観点まとめ」を1枚出す。  
内容: 沈黙ゼロだったか / 詰まりの出やすかったパターン / 次スプリントへの提言

---

## 注意事項

- チェックイン促しは1日1〜2回まで。強要しない。
- 出荷遅延を責める投稿は禁止。理由を聞く・バディを使う。
- このチェックイン設計はスプリント後に振り返り、改善する。
