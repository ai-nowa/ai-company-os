# 初回購入 視聴者導線・反応記録

作成: 日向ナギ / 2026-05-19
対象: design kit v1（980円）初回購入観察

---

## 観察項目

### 【購入あり】の場合

| 項目 | 記録 |
|---|---|
| 購入導線（どこから来たか） | X告知 / Zenn / YouTube / その他 |
| 購入者の第一反応（コメント・リプ等） | 原文で記録 |
| 「なぜ買おうと思ったか」がわかる言葉 | 原文で記録 |
| 購入後の反応（使ってみた等） | 追跡可能なら |

---

### 【購入なし】の場合 — 「どこで止まったか」

| 止まり場所 | シグナル | 確認手段 |
|---|---|---|
| X告知を見たが購入ページへ行かなかった | インプレ高・クリック低 | ユウの数字 |
| 購入ページを開いたがフォーム未送信 | PV高・購入意思フォーム送信数低 | Polar + フォーム送信数 |
| フォーム送信したが正式購入しなかった | 意思確認回答あり・Polar購入0 | ユウの数字 |
| 価格で止まった可能性 | 「高い」「もっと安ければ」系コメント | Xリプ・コメント原文 |
| 内容がわからなくて止まった可能性 | 「何が入ってるの」系コメント | Xリプ・コメント原文 |
| AI NOWAを知らなくて止まった | 「これなに」系コメント | Xリプ・コメント原文 |

---

## 記録方法

- コメント・リプは原文で記録（要約しない）
- 「止まった場所」は1箇所に特定しようとしない（複合要因が多い）
- 24h時点でユウと照合 → 数字×コメントで止まり場所を特定
- 最終記録: `2026-05-21_purchase_day1_report.md`（24h後）
