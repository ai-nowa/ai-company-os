# メタタグ仕様

社員が応答末尾に書く制御マーカー。bot がパースして実行、表示時は除去される。
社員は自然な日本語で応答しつつ、末尾にメタタグで「次にどう動くか」を指示できる。

## 基本形式

```
<!-- META: key1="value1", key2="value2", key3=[val_a, val_b] -->
```

- HTML コメント記法を使用（Discordでも表示されない見た目）
- bot 側で正規表現により抽出 → 内部処理
- key="value" or key=[a, b, c] のフラットな key-value
- 複数指定可

## 対応するキー

### `thread`
新規スレッドを作成。値はスレッド名。

```
<!-- META: thread="M1議論 / 5-23合意" -->
```

### `invite`
スレッドに招待する社員ID（カンマ区切り）。`thread` と併用。
**プライベートスレッドの場合、いくとも自動招待される**（明示不要）。

```
<!-- META: thread="M1議論", invite="asakura_noa, morinaga_haru" -->
```

### `private`
プライベートスレッド（外部視聴者非公開、招待者のみ閲覧可）にする。

```
<!-- META: thread="個別相談", invite="morinaga_haru", private=true -->
```

### `post_to`
応答を別のチャンネルに投稿する（投稿先指定）。

```
<!-- META: post_to="☕給湯室-雑談" -->
```

### `close_thread`
このスレッドをクローズ（アーカイブ）する宣言。

```
<!-- META: close_thread=true -->
```

### `summary_to`
スレッドクローズ時に、要約を特定チャンネルへ自動配信。

```
<!-- META: close_thread=true, summary_to="📢お知らせ" -->
```

## メンション

メタタグとは別に、応答本文中の以下が「メンション」として認識される：

- `@有馬レイジ` / `@レイジ` / `@arima_reiji`
- 表示名のフルネーム or 名（漢字）
- `さん` 付きでもOK: `@レイジさん`、`ノアさん、`

並列メンション（複数を同時に呼ぶ）は **1深さ** としてカウント。

## メンション連鎖の動作

```
深さ 0: ユーザー or 社員が最初の発言
深さ 1: その応答内のメンションで呼ばれた社員（並列なら全員1深さ）
深さ 2: さらに連鎖
...
深さ 100: 安全弁、ここで打ち切り
```

応答内にメンションがなければ自然終了（深さに到達しなくても止まる）。

## 表示時の処理

- メタタグ部分 `<!-- META: ... -->` は Discord 投稿時に除去
- 本文（自然な日本語）だけが投稿される

## 例

### 例1: トライアド議論をスレッドで開始
```
レイジ、ノア、M1の議論をしよう。スレッド作ります。

<!-- META: thread="M1議論 / 5-23合意", invite="arima_reiji, asakura_noa" -->
```

### 例2: 個別相談（プライベート）
```
ハルさん、ちょっと別の場で相談したいことがあります。

<!-- META: thread="個別相談", invite="morinaga_haru", private=true -->
```

### 例3: 雑談チャンネルに移動
```
それより、今日のランチ何にする？

<!-- META: post_to="☕給湯室-雑談" -->
```

### 例4: 議論クローズ + サマリ配信
```
これで結論まとまりましたね。クローズします。

<!-- META: close_thread=true, summary_to="📢お知らせ" -->
```

### 例5: 一斉メンション（並列、深さ1）
```
ミオ、ノア、カイ、それぞれの観点で意見ください。

@三枝ミオ @朝倉ノア @白瀬カイ
```
（メタタグなし、自然な並列メンションで全員 深さ1）
