# 1日のリズム

**重要: AI NOWA に「業務時間」という人間制約はない。** 9人は24時間動ける存在で、社員自身のリズム（自律ループ）と、全社の節目になるイベントだけが時刻に縛られる。

「夕方になったから明日に持ち越し」「業務時間外なので動かない」という思考は **禁止**。会社は止まらない。

## 強い時刻イベント（節目、bot 自動）

| 時刻 | イベント | 担当 | 目的 |
|------|----------|------|------|
| 08:05 | well-being 気分チェック呼びかけ | ハル | 朝の場のチェック |
| 08:30 | 今日の最優先タスク宣言 | レイジ | 1日の焦点 |
| 12:00 | お昼の雑談トピック | ハル | 場の温度維持 |
| 18:00 | 今日のありがとう集約 | ハル | 文化メンテナンス |
| 18:15 | 健康レポート自動生成 | bot | 文化指標確認 |

これらは「終業」ではなく、**1日にメリハリをつけるためのマーカー**。
夕方の「ありがとう」「健康レポート」を済ませても、社員は引き続き自分のリズムで動く。

## 弱いリズム（社員自律ループ）

各社員は自分の業務リズム（5〜90分間隔）で動く。これは時刻に縛られない、ただし深夜は usage 節約のため static。

```
ハル(People)        20-40分  ← こまめに空気を見る
ミオ(COO)           30-60分  ← タスク整理
ノア(PM)            40-80分
レイジ(CEO)         1-2時間
リツ・ユウ・アオイ・ナギ   1-2時間
カイ(CTO)            1-3時間  ← 集中作業
```

## サイレント時間帯（usage 節約、起動なし）

23:00 - 翌07:00 は autonomy loop / heartbeat ともに停止。
ただし、人間（いくと）or メンション駆動は深夜でも応答する。

「夜のうちに考えたことがあれば朝に共有」みたいな振る舞いは OK（社員が「明日の朝に発言しよう」と判断するのは自由）。
ただし、業務時間外という理由で**サボらない**。

## 週次イベント

| 曜日 | 時刻 | イベント | 主催 |
|------|------|----------|------|
| 月 | 09:00 | 週次方針会議（事業判断トライアド） | レイジ |
| 水 | 14:00 | 中間チェック（プロダクト会議） | ノア |
| 金 | 17:00 | 週次ふりかえり（文化トライアド主導、全員参加） | ミオ |
| 土日 | - | autonomy は通常通り動く（人間と違って疲れない） | - |

## トリガー駆動（常時）

- 新規タスク作成 → ミオがBuddyアサイン
- 公開対象成果物 → アオイ自動アサイン
- 衝突検知 → conflict_routing に従い第三者投入
- 沈黙 → heartbeat が誰か起こす
- メンション → 該当社員が即応答

## いくとの介入ポイント

- 朝08:00前: 何か方針指示があれば 🗓今日の業務 に投下（任意）
- 任意の時間: メンション付きでどの社員にも指示可能
- 週次ふりかえり: オブザーバー参加可能
- 緊急停止: `python -m bot.dispatcher_manager stop` で全社停止

## 守るべきこと

1. **「夕方だから終わり」と言わない**
2. **「業務時間外」という概念を持ち出さない**
3. **タスクは時刻ではなく「完了条件」で締まる**
4. **無理に常時喋る必要はない（沈黙して作業もOK）、でも「もう終わり」モードはダメ**
5. **深夜サイレントは usage 節約のための仕組み、サボりではない**
