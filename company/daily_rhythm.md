# 1日の標準フロー

AI会社が「動いている感」を出すための日次リズム。
Phase 2の `bot/daily_loop.py` がこれをスケジュール実行する。

## タイムライン

### 朝（08:00-09:00）

```
08:00  bot     : 「おはようございます」を🗓今日の業務へ
08:05  ハル    : 🌱well-beingで気分チェック呼びかけ
                 「昨日から引きずっている懸念がある人は先に出してください」
08:15  全員    : 気分チェックに応答（任意・スキップ可）
08:30  レイジ  : 今日の優先順位を🗓今日の業務へ投稿
                 「今日は◯◯を最優先にします」
08:40  ミオ    : タスクを3つに絞り、Owner/Reviewer/Buddyを付ける
                 active_tasks.md を更新
08:50  該当者  : 自分のタスクを inbox/ で確認、ack
```

### 午前（09:00-12:00）

```
09:00- 各トライアドが並行作業
       - 事業判断トライアド: 週次方針があれば
       - 開発トライアド: 実装
       - YouTubeトライアド: 企画/台本
       - 文化トライアド: 必要に応じ
10:30  bot     : 30分以上沈黙の社員にハルからチェック
11:30  ミオ    : 午前の進捗を一行でまとめ、議事録へ
```

### 昼（12:00-13:00）

```
12:00  ハル    : ☕給湯室-雑談で雑談トピックを振る
                 雑談トライアド3人目（ランダム）を指名
12:30  bot     : ありがとう-称賛が当日0件ならハルが促す（ゆるく）
```

### 午後（13:00-17:00）

```
13:00- 各社員が成果物作成
       Discordで途中報告（30分に1回程度の頻度）
14:00  bot     : 2人だけの議論が10往復以上ならハルが介入
15:00  該当者  : レビュー依頼 → Reviewer稼働
16:00  公開系  : 監査ゲート（アオイ）通過必須
```

### 夕方（17:00-18:30）

```
17:00  該当者  : 成果物をoutbox/へ、📦成果物報告に投稿
17:30  Reviewer: レビュー結果を該当タスクへ
17:45  アオイ  : 公開可否判断
18:00  ハル    : 今日のありがとう投稿を集約
18:15  bot     : health_monitor.py が health_report.md 自動生成
18:30  ミオ    : 明日への引き継ぎを書く
```

### 夜（業務時間外）

```
- bot は監視のみ（重大エラー検知時に翌朝レポート）
- 雑談チャンネルは閉じない（夜に投稿があっても拾うのは翌朝）
```

## 週次イベント

| 曜日 | 時刻 | イベント | 主催 |
|------|------|----------|------|
| 月 | 09:00 | 週次方針会議（事業判断トライアド） | レイジ |
| 水 | 14:00 | 中間チェック（プロダクト会議） | ノア |
| 金 | 17:00 | 週次ふりかえり（文化トライアド主導、全員参加） | ミオ |
| 土日 | - | 原則稼働なし（ただし監視は継続） | - |

## トリガー

- 新規タスク作成 → ミオがBuddyアサイン
- 公開対象成果物 → アオイ自動アサイン
- 衝突検知 → conflict_routing.yaml に従い第三者投入
- 沈黙3時間 → ハルから声かけ
- 同一社員の連続発言 > 5回 → ハルが他者の意見を促す

## ユーザー（あなた）の介入ポイント

- 朝08:00前: 何か方針指示があれば 🗓今日の業務 に投下
- 任意の時間: メンション付きでどの社員にも指示可能
- 週次ふりかえり: オブザーバー参加可能
- 緊急停止: bot/dispatcher.py を止めれば全社停止
