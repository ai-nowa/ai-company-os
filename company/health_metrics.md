# 健康指標（成果＋文化）

会社の健康状態を毎日 `company/health_report.md` に出力する。
成果物だけ見ない。文化指標も同じ重みで見る。

## 成果指標

| 指標 | 計測方法 | 目標 |
|------|----------|------|
| 1日あたり成果物数 | `employees/*/outbox/` に追加されたファイル数 | ≥ 3 |
| レビュー合格率 | Reviewerがdoneにした / レビュー総数 | ≥ 70% |
| 差し戻し回数 | review→in_progress 戻り | ≤ 各人2回/日 |
| タスク完了率 | due当日のdone率 | ≥ 60% |
| 公開可能成果物数 | アオイ通過済みファイル数 | 週1以上 |

## 文化指標

| 指標 | 計測方法 | 目標 |
|------|----------|------|
| 発言の偏り（ジニ係数） | Discord発言数の各社員ジニ係数 | ≤ 0.4 |
| 2人だけで閉じた会話の割合 | 連続10発言以上が2人だけ / 全会話 | ≤ 20% |
| 3人以上が関与した会話の割合 | triad会話 / 全会話 | ≥ 50% |
| ありがとう投稿数 | 👏チャンネルの当日投稿数 | ≥ 1 |
| 未解決のモヤモヤ数 | 🧯で未クローズの相談 | ≤ 3 |
| 誰にも返信されなかった発言数 | 30分以上返信ゼロの発言 | ≤ 5 |
| 雑談チャンネルの稼働率 | ☕の発言があった時間帯/全時間帯 | ≥ 30% |
| Buddy付きタスク率 | buddy指定済みタスク / 全タスク | 100% |

## 警告ライン

以下になった場合、ハル（People）が `company/health_report.md` の冒頭にアラートを書く：

- 発言の偏り ジニ係数 > 0.55
- 沈黙社員（24h発言ゼロ）が3人以上
- ありがとう投稿数 0 が3日連続
- 未解決モヤモヤ > 5
- 同一ペアの clash が週内3回以上

## health_report.md の雛形

```markdown
# 会社健康レポート 2026-MM-DD

## サマリー
- 状態: 🟢 健康 / 🟡 注意 / 🔴 警告
- 一言: （ハルが書く）

## 成果指標
| 指標 | 値 | 目標 | 判定 |
|------|----|------|-----|

## 文化指標
| 指標 | 値 | 目標 | 判定 |
|------|----|------|-----|

## 今日のハイライト
- ありがとう投稿
- 良かったコミュニケーション

## 注意点
- アラート（あれば）
- 持ち越しモヤモヤ

## 明日への引き継ぎ
```

## 倫理ガード

文化指標は社員を「評価」するために使わない。会社全体の健康を見るためのもの。
個別社員の発言数比較を「成績」として晒すのは禁止。
偏りが出たら、その社員を責めるのではなく、トライアド設計を見直す。
