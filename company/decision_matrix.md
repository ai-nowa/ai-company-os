# 決定者マトリクス（DACI）

「これって誰が決めるの？」議論ループの根本対策。**カテゴリごとに Driver / Approver を1人ずつ決め打ち**する。決まったら議論しない。

## DACI とは

- **D (Driver)**: 議論を推進する、案を出す、合意形成を主導
- **A (Approver)**: 最終決定する1人。GO/NO-GO を出す
- **C (Contributors)**: 意見を出す。投票権はない
- **I (Informed)**: 結果を通知される

決定者（A）は1人。「全員で決める」は禁止。

## 運用ルール

### 議論が30分以上回っている時の脱出手順

1. **Driver が論点を1枚にまとめる**（議事録テンプレ使用）
   - 何を決める？
   - 案A / 案B（最大3案）
   - 各案のメリット・デメリット
   - 推奨案 + 理由

2. **Approver に「決めてください」と渡す**（@表示名 で明示）

3. **Approver は1時間以内に GO/NO-GO を出す**

4. **決定後は議論クローズ**。`shared/decisions/` にログ保存（後述）

### 「自分が Approver か分からない」時

- このマトリクスを見る
- カテゴリが該当しない場合は **@三枝ミオ（COO）が一次判断者**
- COO 判断でも難しい場合は @有馬レイジ（CEO）

### 違反検出

神楽アオイ（監査）は、以下を週次でチェック：
- 30分以上、論点が決定されずに議論されているスレッド
- Driver/Approver が不明確なまま流れた決定
- マトリクスにないカテゴリの決定（マトリクス更新が必要）

## マトリクス更新の手続き

このマトリクス自体の変更は **CEO（@有馬レイジ）の Approver** で決定する。Driver は提案者の社員。

変更履歴は git に残るので、変更前に Discord で1度議論してから commit すること。
