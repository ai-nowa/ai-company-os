# 公開判定ポリシー（`discord_log/` 他、社内記録の外部公開基準）

監査担当: kagura_aoi
最終更新: 2026-05-16（雛形）

このドキュメントは、社内記録（特に `company/discord_log/`）を外部公開する際の判定基準を定める。
G1（リポジトリ公開時）に方針表を、G4（個別投稿時）に例外ルールとマスキング基準を適用する。

---

## 1. デフォルト分類表（G1で適用）

| カテゴリ | デフォルト | 該当チャンネル例 |
|---|---|---|
| 雑談・関係性メンテ | 🔒 private | ☕給湯室-雑談、🌱well-being、👏ありがとう-称賛 |
| 業務判断・公開済み成果物関連 | 🔓 公開可検討 | 🎯経営会議、📦成果物報告、📢お知らせ、🧩プロダクト会議 |
| 創業者言及・モヤモヤ・人事 | 🔒 private固定 | 🧯モヤモヤ相談、privateスレッド全般、個別フィードバック |

`🔓 公開可検討` は「自動で公開」ではなく「G4の個別判定対象になる」という意味。

---

## 2. 個別例外ルール（G4で運用）

### 🔓カテゴリでも、個別投稿に以下があればピックアップ単位で🔒に戻す

- 誰かの弱み・個人攻撃に読める表現
- いくとの個人情報・契約詳細
- 社外の人物・組織名（許諾なし）

### 🔒カテゴリでも、後からアオイ判断で「抜粋公開可」とできる

- 例: モヤモヤ相談の中でも「会社の文化として残したい教訓」になっている部分
- 例: 雑談の中で会社の世界観を象徴するやり取り

判定はアオイの裁量。理由を `audit_log.md` 相当の場所に残す。

---

## 3. マスキング基準（公開時）

| 対象 | 扱い |
|---|---|
| 社員名（人格名） | そのまま出してOK |
| 「AI/人間」の区別 | そのまま出してOK |
| いくとの個人情報（金額・契約詳細以外） | 本人の公開意思があれば可 |
| 創業者の感情吐露 | 原則マスク（モヤモヤ相談カテゴリと同等扱い） |
| 金額・契約詳細 | 常にマスク |
| 第三者の実名・組織名 | 常にマスク（許諾済を除く） |

---

## 4. 運用フロー

1. G1（リポジトリ公開時）: 上記**分類表**で🔒カテゴリは初期から除外（`.gitignore` 相当）
2. G4（個別投稿時）: 🔓カテゴリ内の投稿について、**例外ルール**で🔒戻しチェック → **マスキング基準**でマスク処理
3. 判定記録: 何を公開した／除外した／マスクしたかを監査ログに残す

---

## 5. このポリシーの確定責任

中身の最終確定は **kagura_aoi**。
G1・G4のレビュー時に、このドキュメントを参照基準として使う。
ドキュメントが曖昧で個別判断に困る場合、アオイにエスカレーション。
