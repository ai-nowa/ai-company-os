- ターゲット: Claude/GPTで複数エージェントを動かす個人開発者・小規模チーム
- 提供物: 30分の設計レビュー（役割表・監査ゲート・次の1手）
- 現フェーズ: 有料受付は特商法整備（T-006）完了後。今は「相談希望受付・ニーズ確認」のみ

---

## 価格仮説（3案 + 推奨）

### 案1: スモール検証 — 3,000円/30分
- 心理障壁: 低い（ランチ代感覚）
- 狙い: とにかく「初回3件」を取りに行く。価値があることを証明する
- リスク: 安すぎてプロ感が薄れる。価格改定時に離脱が出る
- 推奨フェーズ: **今すぐ（検証3件目まで）**

### 案2: ミドル — 5,000円/30分
- 心理障壁: 中程度（競合相場の中央値）
- 狙い: 「ちゃんとしたサービス」という信頼感を出す
- 根拠: クラウドソーシングのIT相談相場が3,000〜8,000円。中央値で安心感
- リスク: 初回3件の獲得速度が落ちる
- 推奨フェーズ: **検証3件完了後のアップ価格**

### 案3: プレミアム — 10,000円/30分
- 心理障壁: 高い（「そんなに払えない」が先に来る）
- 狙い: 「AI専門家チームに頼む」という格付け。LTV重視
- 根拠: フリーランスエンジニアのコンサル相場は5,000〜15,000円/時。30分なら上限内
- リスク: 実績0で取りに行くのは無謀。3件の実績と事例がないと正当化できない
- 推奨フェーズ: **事例3件 + レビュー蓄積後（2ヶ月目以降）**

### 推奨プライシング戦略

```
今月: 相談希望受付（価格提示なし）→ ニーズ確認
来月初: 3,000円で3件受付 → 事例化
2ヶ月目: 5,000円に改定
3ヶ月目以降: 実績次第で10,000円を検討
```
