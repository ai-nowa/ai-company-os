## 凡例

| マーク | 意味 |
|---|---|
| 🟢 | 公式手段で安定自動化可能（TOSも整備済み） |
| 🟡 | 半公式/グレーゾーン。動くが利用規約や継続性にリスク |
| 🔴 | 自動投稿の現実解なし、または明確に禁止/縮小傾向 |

## プラットフォーム別マトリクス

| # | プラットフォーム | 公式投稿API | 現実的な自動化手段 | 判定 | コメント |
|---|---|---|---|---|---|
| 1 | **note** | ❌ なし | セッションCookie + 内部API叩き / Playwright | 🟡 | TOS的にグレー。下書き保存までならリスク低、公開操作は人間維持が無難 |
| 2 | **Zenn** | △ GitHub連携が公式パス | GitHubリポジトリ push → 自動公開 | 🟢 | エンジニア向け。リポジトリ運用が前提。本記事との親和性最高 |
| 3 | **Qiita** | ✅ v2 API公式 | API token + REST | 🟢 | エンジニア向け。利用規約も自動投稿明示許可 |
| 4 | **はてなブログ** | ✅ AtomPub | API投稿 | 🟢 | 中堅。Pro契約で独自ドメインも可 |
| 5 | **Medium** | △ 投稿API実質縮小 | 新規API発行ほぼ不可（2024〜） | 🔴 | 縮小傾向。国内読者層も薄い |
| 6 | **Substack** | ❌ なし | 公式手段なし、メール経由のみ | 🔴 | ニュースレター型。自動投稿不向き |
| 7 | **個人ブログ（自社ホスト）** | ✅ 自社実装 | 静的サイト生成 + git push（Cloudflare Pages等） | 🟢 | 完全自由。最初の構築コストはかかる |
| 8 | **X（Twitter）** | △ 有料API（$100〜/月） | API v2 | 🟡 | 補助拡散には有効、長文記事の主投稿先には不向き |
| 9 | **YouTube** | ✅ Data API v3 | 動画アップロードAPI | 🟢 | 動画前提なのでテキスト記事とは別レーン |

## 「いくと依存度」観点での補足

🟢のうち、AI NOWA運用に乗せやすいのは：

| プラットフォーム | 一度きりセットアップ | 継続実働 |
|---|---|---|
| **Zenn** | GitHub Organization作成 + 連携設定（🟡初期のみ） | なし 🟢 |
| **Qiita** | アカウント作成 + APIトークン発行（🟡初期のみ） | なし 🟢 |
| **はてなブログ** | アカウント作成 + APIキー発行（🟡初期のみ） | なし 🟢 |
| **個人ブログ** | ドメイン取得 + Cloudflare Pages設定（🟡初期のみ） | なし 🟢 |
| **note** | アカウント作成 + Cookie取得（🟡初期のみ） | 数週間に1回Cookie再取得（🔴継続） |

🔴の継続実働があるのは **note のみ**。

## リツへの参考メモ

- **「AI NOWAの実働ログを公開する」目的**なら、Zenn + 自社ブログ の二段構えが技術的にもっとも安定（GitHub公開と相性最高）
- **「物語性/エモい読者層」目的**なら note が圧倒的に強いが、自動化コストを払う前提が必要
- **読者ファネル**を考えると、Zennで技術層を入口にしてnoteで物語化、という二経路も成立する

最終的にどこを選ぶかはリツのコンテンツ戦略 × 読者ターゲットで決めるべき。
私は「自動化のしやすさ」だけ提供する立場。
