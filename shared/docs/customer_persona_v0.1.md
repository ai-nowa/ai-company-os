| 項目 | 詳細 |
|------|------|

### ペルソナB: 「副業・小規模チームでAIを業務導入したい人」

| 項目 | 詳細 |
|------|------|
| 人物像 | 40代前後、マネージャー or 経営者。チームの業務にAIを入れようとしている |
| やろうとしていること | 繰り返し業務（コンテンツ制作、調査、議事録）をAIにやらせたい。でも品質管理が不安 |
| 詰まっているポイント | 「AIにやらせる」と「自分でやった方が早い」の壁を越えられない。誰かに設計を見てほしいが、相談相手がいない |
| 既存の代替手段 | ChatGPTのプロンプトエンジニアリング本 / 社内勉強会 / コンサル（高い）|
| 「誰が一番嬉しいか」 | 「AIチームの動かし方を体系的に教えてくれる人」を探していたが、コンサルは高すぎる。安価に試せる相談窓口を求めている |

---

## ペイン（2ペルソナ共通）

1. **役割設計がわからない** — 何をAIに任せて、何を人間が持つべきか判断できない
2. **暴走・品質保証が怖い** — AIが勝手に動いて変なものを出すリスクをどう抑えるか不明
3. **意思決定の記録が残らない** — なぜその設計にしたのかのログが残らず、後で混乱する
4. **相談相手がいない** — 技術者に聞くと細かい話になりすぎる。ビジネス文脈で話せる人がいない

## 既存代替案の弱点

| 代替手段 | 弱点 |
|---------|------|
| Twitterで聞く | 体系的な答えが得られない。浅い |
| Zenn/Qiita記事を読む | 実装レポートが多い。設計判断の根拠がわからない |
| 一般AIコンサル | 高額（5万〜）。1回のMTGで終わる |
| 社内勉強会 | 知識が属人化。外部事例がない |

## 「誰が一番嬉しいか」

**AI NOWAの設計記録を読んで、自分でも試したくなった人。**

- Zenn記事「AIチームの設計記録」を読んで「仕組みは分かった。でも自分の場合どうすればいいか」と詰まっている
- 1〜2時間で設計の方向性をもらえれば自分で動ける
- 「高いコンサルは不要、でも独学だけだと止まる」というレイヤーの人

## 受けない相談（スコープ外）

| スコープ外 | 理由 |
|-----------|------|
| 「AIで稼ぎたい」（収益モデルの相談） | 事業設計は別の専門性 |
| 「プロンプトを書いてほしい」（代行） | 設計相談ではなく外注 |
| 「社員100人への展開」（大規模DX） | 運用体制の設計が別途必要 |
| 「AIで〇〇を作ってほしい」（開発委託） | 相談ではなく開発案件 |
