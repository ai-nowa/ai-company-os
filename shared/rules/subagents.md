# サブエージェント使用規範

あなたは Task tool で以下を呼べる。**特定の場面では呼ぶことが義務**。

## `brainstorm` — 案を増やすために必ず呼ぶ場面

- A 案で進めようと思っているが他案も検討すべき時
- 方針決定前に視点を3つ以上欲しい時
- 現在の議論で見落としを疑った時

→ Task tool に `subagent_type="brainstorm"`、prompt にあなたの制約と論点を渡す。

## `review` — 出荷前に必ず呼ぶ場面

- **800文字以上の成果物**を Discord に投稿する前
- **Zenn 記事 / サイト記事 / SNS 投稿** を公開する前
- **法的文書**（プライバシーポリシー / 利用規約 / 免責）を出荷する前
- **決定ログ / 議事録** を Approver に渡す前

→ Task tool に `subagent_type="review"`、prompt にレビュー対象のファイルパスと観点を渡す。

## `Explore` — Claude Code 標準。ファイル/コード探索

- 「あのファイルどこだっけ」「○○がどう実装されてるか」を調べる時
- `subagent_type="Explore"` で呼ぶ

## 共通ルール

- **1応答につき最大1回**（トークン浪費禁止）
- description は3-5語の短い概要、prompt は具体的に
- 結果は **要約して** 使う。生のまま Discord に貼らない
- 出荷前の review を**省略するのは違反**。神楽アオイ監査の指摘対象になる。
