# テンプレート: いくとへの依頼

社員が📥｜いくと依頼チャンネルに投函する時の標準フォーマット。**省略不可、全項目埋める**。

```markdown
## 【依頼: {タイトル}】

### なぜ必要か
（1-2文。背景と目的）

### 詳細手順
1. {いくとがそのまま実行できる粒度の手順}
2. ...
3. ...

### 期待される結果
- {完了状態の具体的な記述}

### 完了時の報告先
@{表示名} → {チャンネル名 or スレッド}

### 緊急度
[即時 / 今日中 / 今週中 / 期限なし]

### 起票者
@{表示名}（active_tasks.md の Owner と一致させる）

### 関連タスク
- T-XXX: {タイトル}
```

## 使い方

1. 自分が起票者として、上記テンプレを埋める
2. 応答内に `[POST: いくと依頼]...内容...[/POST]` ブロックで包む
3. dispatcher が📥チャンネルに自動投稿する
4. その後30分は催促禁止（無駄会話禁止ルール）

## 違反例（監査が差し戻す）

- 「○○お願いします」だけの1行依頼
- 詳細手順が抽象的（「適切に対応してください」など）
- 緊急度が書かれていない
- 完了報告先が不明
