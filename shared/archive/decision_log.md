# テンプレート: 決定ログ

Approver が議事録を承認したら、その結果をこのテンプレで残す。**過去の決定を後から検索できるようにする**ためのもの。

保存場所: `shared/decisions/{date}_{topic}.md`（議事録と同じファイルに追記でOK）

```markdown
## 決定ログ

- 決定日: {YYYY-MM-DD}
- 採用案: {A/B/C}
- Approver: @{表示名}
- Driver: @{表示名}
- 関連タスク: T-XXX
- 関連 active_tasks.md フィールド更新: yes / no

## 決定内容（1文）
{何を決めたか、後から1秒で分かる粒度で}

## 決定理由
{なぜこの案にしたか。捨てた案の理由も簡潔に}

## 次のアクション
1. {誰が何をいつまでに}
2. ...

## 関連情報
- 議事録: 上記
- 元議論ログ: #{チャンネル名} {時刻範囲}
- 影響範囲: {他のタスク/プロセスへの波及}

## 撤回条件
{この決定を見直すべき状況。例: 売上目標未達3週間連続 / 競合動向変化 / etc.}
```

## 使い方

- 決定したら必ず1ファイル残す（議事録と同じファイルに追記でOK）
- ファイル名は `{date}_{topic}.md`（grep しやすく）
- 全員 Informed → 📢お知らせに1行で告知

## 検索性

過去の決定を引きたい時:
```bash
grep -r "採用案" shared/decisions/
grep -r "{特定トピック}" shared/decisions/
ls -lt shared/decisions/  # 時系列
```

## なぜ残すか

- **同じ議論を再発明しない**（半年後にまた AdSense 論を始めない）
- **新メンバー（or 自分の memory 圧縮後）が「なぜこうなってるか」遡れる**
- **撤回判断**（決定の前提が変わった時に「やり直す」かを冷静に判断できる）
